# BulkElectronDensity

Bulk electron density of the buffer and its uncertainty (`ρₑ`, in
`src/bulk-electron-density/bulk-electron-density.jl`), and the buffer solute types
(`Solute`, `Protein`, `NonBiological`, `DNA`, `RNA`). Partial molar volumes at
infinite dilution and the water density are internal.
