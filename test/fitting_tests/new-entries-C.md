# New entries C (SASDA.. to SASDG.., proteins)

Thirty-five protein entries wired 2026-11-18 by agent C (36 runs: SASDC36 has two), none run yet. Under the owner's round-8 rules: one atomic PDB model per entry, a depositor .fit with a recomputed chi^2 within 10 % of the stated one, buffer, pH, temperature and wavelength from the SASBDB entry (the papers were NOT consulted for any of them: every header says "SASBDB metadata only"), no q cut. The size limit was lifted during the work; seven entries have 9000 or more heavy atoms (see "Run time" below). Rows follow the Replacement-entries table format. Fixtures are packed (`bysl fixtures pack`), scripts parse-checked with `Meta.parseall`, lines at most 92 columns; no fit, smoke run or benchmark was run.

## Open points

- **Policy for chi^2 mismatches (used throughout).** refChi2 is the depositor value that my recomputation against the .dat reproduces (free scale; every .fit gave a free scale within 0.5 % of 1, fitScale 1.0 for all, the .fit q is always in 1/A even when the .dat is in 1/nm). Where the .fit header and SASBDB disagree, the matching one is used and both are in the script header: SASDA38 (SASBDB 1.51 = recomputed 1.508; header 1.228), SASDA28 (SASBDB 1.13 = recomputed 1.127; header 1.062), SASDDH9 (header 0.889 = recomputed 0.887; SASBDB 1.222). SASDE35 (0.749 vs 0.704) and SASDEC5 (0.951 vs 0.964) are FoXS fits with about 74 points. SASDFQ6's FoXS reference is 4.034 (SASBDB) against 4.167 recomputed.
- **Depositor fit range shorter than the curve** (refChi2 is then not like for like with the fitted range; no q cut applied, each header states it): SASDBZ5, SASDCQ8, SASDD33, SASDDL3, SASDFQ8, SASDF55 (q to 0.30), SASDF93 (q to 0.30), SASDBZ2 (q to 0.25), SASDE36.
- **Poor depositor fits kept on purpose** (the model, not the data, is poor): SASDEM3 5.025, SASDEZ6 4.792, SASDFQ6 4.034, SASDGL2 3.382, SASDE36 2.821, SASDG97 2.201.
- **Flagged assumptions, all in the script headers.** EDTA taken as the disodium salt (H2EDTA + Na+): SASDBZ5, SASDA28, SASDA38. Sodium azide percentages read as w/v (0.2 % = 30.8 mM, 0.1 % = 15.4 mM): SASDGK2, SASDGH2, SASDGG2, SASDFZ3. Glycerol percentages read as v/v: SASDC36, SASDFZ3, SASDFP8, SASDFQ8, SASDF75. TCEP in SASDF75 and DTT in SASDC36/SASDEP7/SASDEQ7 added as the neutral solute, no counter-ion. No salt assumed where SASBDB lists none: SASDCQ8 (Tris only), SASDEB5 (HEPES only), SASDE27/SASDEZ6/SASDGD6 (phosphate or acetate only).
- **PBS entries** (SASDDL3, SASDE35, SASDEC5): SASBDB gives only the name; the standard 1x recipe (137 mM NaCl, 2.7 mM KCl, 10 mM Na2HPO4, 1.8 mM KH2PO4) is assumed, as in the earlier PBS entries. SASDDL3's SASBDB pH is 7.0, not the nominal 7.4; it is used as given.
- **Model versus SASBDB molecule list.** SASDFZ3's model has three chains (A, B, C) while SASBDB lists YjhC as a dimer; SASDD33's model has 12 chains (both components listed as hexamers); SASDA38's model has one chain labelled E and SASDA28's has a blank-and-ABCD chain field. The depositor fits are the evidence the model matches the curve.
- **Altloc atoms** are counted twice by the loader: SASDEQ7 22, SASDCQ8 18, SASDEM3 330, SASDGH2 130, SASDFZ3 453, SASDEB5 38, SASDFP8 128, SASDFQ8 26, SASDGD6 30, SASDF93 160, SASDD33 72, SASDEC5 64. Models with deposited hydrogens (pdb2pqr re-places them): SASDEM3, SASDGK2, SASDE27, SASDGH2, SASDFZ3, SASDF55, SASDF75.
- **Six entries use the FoXS reference label**: the .fit of SASDDH9, SASDE35, SASDFP8, SASDEC5, SASDFQ6 and SASDE36 is a FoXS profile (SASBDB lists some as Chimera or PDB); the label follows the file header (CRYSOL if it has a Dro: field, else FoXS).
- **Screening was by SASBDB metadata**, so heavy-atom counts, ligand names (all resolve in components.tsv) and units are checked but the papers are not; a later pass with the papers could replace the SASBDB buffers.
