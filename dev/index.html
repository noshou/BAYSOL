BAYSOL.jl

Bayesian CRYSOL fitting for proteins (and, in future, nucleotides).

BAYSOL.BAYSOL — Module

Bayesian CRYSOL: NUTS sampling of the CRYSOL nuisance parameters (solvent density, hydration-shell contrasts) with the excluded-volume correction profiled out.

The package root only assembles the modules, one folder per module under src/, in dependency order, and re-binds the pipeline entry points of Report so they are reachable as BAYSOL.seed_model, BAYSOL.run_model and BAYSOL.write_report.
