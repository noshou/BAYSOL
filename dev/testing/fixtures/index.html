Test fixtures

Data fixtures are grouped by kind, one directory per kind:

directorycontents
form-factors/X-ray form-factor oracle data (f0.csv, f1f2.csv) from xraydb
molecules/Real RCSB PDB/mmCIF structures (10 protein, 6 nucleic-acid or mixed ones), used by StructureSource/pipeline tests
components/Three wwPDB Chemical Component Dictionary files, for the component-lookup tests
experiments/Real SASBDB entries (curve + fit + model + source paper), one dir per case; 57 entries: 27 protein-only and 30 with DNA or RNA (16 nucleic acid only, 14 protein and nucleic acid)

Component dictionary fixtures

Three files of the wwPDB Chemical Component Dictionary, one mmCIF per component, downloaded unmodified on 2026-10-15 from https://files.rcsb.org/ligands/download/<ID>.cif. The bundled table src/MolecularStructure/components.tsv already holds all three ids, so test_componentcache.jl and test_nucleotide_seed.jl rewrite the residue id inside the file to one that is not in the table and serve it through the injectable download hook (MolecularStructure._COMPONENT_DOWNLOAD) or put it in the cache, then check what component returns against the table row.

filecomponentrole in the tests
PSU.cifPSU, pseudouridine-5'-monophosphate (RNA LINKING, parent U, C9 H13 N2 O9 P)the cached or downloaded component of a modified nucleotide
5MC.cif5MC, 5-methylcytidine-5'-monophosphate (RNA LINKING, parent C)the same, as the fake download served by the hook
ATP.cifATP, adenosine-5'-triphosphate (NON-POLYMER)a ligand that is not a nucleotide

No other new data files serve the nucleic-acid tests: their inputs are the fixtures of molecules/ (1BNA, 1RNA, 1SDR, 246D, 1EHZ, 3HDD) and the SASDT55 and SASDG24 models in experiments/, cut or rewritten at run time.

SASBDB experiment fixtures

57 SASBDB entries (27 protein-only, 16 nucleic acid only and 14 protein-nucleic acid mixtures), one directory per case, each holding (subset varies by case): the experimental scattering curve (experimental_data/), the deposited P(r) (pddf/), the depositors' own regularized fit(s) (<CASE>_fit*.fit/.fir/.dat), the fitted/source model coordinates (<CASE>_fit*_model*.pdb/.cif), and a small README.txt naming the source paper and its DOI. The publishers' PDFs are not kept in the repository (they were 85 MB, and redistribution terms vary); fetch a paper from its DOI, which is also in the table below. The 30 nucleic-acid entries are fitted (see the fitting-test README); the depositor fit file keeps the number of the SASBDB fit it belongs to (fit1, fit2 or fit3), whatever the script is called.
