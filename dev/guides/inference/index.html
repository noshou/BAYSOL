Inference

Given a measured curve I_exp(q) ± σ_exp(q) and the geometry-only ForwardCache of Scattering, sample the posterior of four physical parameters with NUTS (AdvancedHMC.jl). Scale, background and CRYSOL's excluded-volume correction c1 are nuisance parameters removed by profiling at every evaluation, so the sampled density is a profiled pseudo-posterior (see "Profiling is not marginalising").

Parameters

ξ = (ρₑ, δρ₁, δρ₂, δρ₃):

  • ρₑ ∈ (0, ∞): electron density of the buffer (CRYSOL's dns).
  • δρ₁, δρ₂ ∈ (−10, 2): convex and concave hydration-shell contrasts, in units of UNIT_OF_δρ = 0.03 e·Å⁻³.
  • δρ₃ ∈ (−ρ̄ₑ/0.03, (φ_max − 1)·ρ̄ₑ/0.03): cavity contrast, written through the cavity occupancy φ = ρ_cavity/ρₑ as δρ₃ = (φ − 1)ρₑ/0.03. φ only derives the bounds; it is not sampled.

c1 is not part of ξ: it is a mean-field bookkeeping factor (one population-mean radius rM over per-atom volumes), not an identifiable physical unknown, so no defensible prior width exists. Scale m and background b (I_calc = m·ĥ + b) are linear and solved in closed form.

The sampler, MAP search, likelihood and report are generic in the number N of sampled parameters (Seed{T,N}, Inferred{S,N}); only the transform Θ/Ξ, θ_prior_moments and the log-prior are specific to the four-parameter priors (and paramKeys, which names the report keys). The Gram matrix stays five-species.

Likelihood

Scale and background (WLS)

With weights wᵢ = 1/σᵢ² and model values hᵢ, the objective χ² = Σ wᵢ(yᵢ − m hᵢ − b)² is quadratic in (m, b), so the normal equations reduce to scalar sums S_w, S_y, S_yy (data only, precomputed in WLSData) and S_h, S_hy, S_hh (model, one O(Q) pass):

\[D=S_{hh}S_w-S_h^2,\quad \hat m=\frac{S_{hy}S_w-S_hS_y}{D},\quad \hat b=\frac{S_{hh}S_y-S_hS_{hy}}{D},\quad \chi^2_{\min}=S_{yy}-\hat m S_{hy}-\hat b S_y\]

D ≥ 0 by Cauchy–Schwarz, with equality only for a flat model; wlsFit throws WLSError for D ≤ 0, n < 3 or σᵢ ≤ 0. Geometrically the fit projects the data onto span{h, 1}: χ²_min = S_yy^c(1 − r²) with r the weighted correlation of data and model, so the likelihood sees only the shape of the model curve (invariant under h → αh + β). Under a correct model χ²_min ~ χ²_{Q−2}, independent of (m̂, b̂), whose covariance is (XᵀWX)⁻¹. WLSFit stores dof = Q − 2; the report's χ² is evaluated on the measured grid with nRaw − 3 degrees of freedom (scale, background, c1), the FoXS/depositor convention. These are conventions, not exact degrees of freedom: the four sampled parameters are not subtracted.

The profiled log-likelihood (wlsProfLl, fixed σ) is

\[\ell(\xi)=-\tfrac12\chi^2_{\min}-\tfrac12\sum_i\ln\sigma_i^2-\tfrac Q2\ln 2\pi\]

Profiling c1

At fixed ξ, ĥ(q;c1) = A + g B + g² C (see Scattering), so profiledCorrs builds A, B, C once and finds the c1 minimising χ² in two gradient-free stages:

  1. A scan over (c_min−ε):ε:(c_max+ε) (28 points at EXCL_VOL_CORR_BOUNDS = (0.8, 1.3), ε = EXCL_VOL_CORR_EPS = 0.02). The three model sums are polynomials in g; with A_i, B_i, C_i, wᵢ, yᵢ per point

    \[S_h=\sum w A+\sum g\,(wB+g\,wC),\qquad S_{hh}=\sum wA^2+\sum g\big(2wAB+g\,(w(B^2{+}2AC)+g\,(2wBC+g\,wC^2))\big)\]

    (S_hy likewise), so after eight coefficient vectors are formed once each grid point is one fused SIMD Horner pass over q, g read from the table _C1Tables.g1.

  2. Brent's method (Optim.jl) in the bracket of the best grid point's neighbours (the padded edge if it is first or last), to EXCL_VOL_CORR_TOL = 1e-8. Every c1 visited lies within half a grid step of a grid point cⱼ, so g(q;c1) = g(q;cⱼ)(c1/cⱼ)³ exp(−q²[k(c1)−k(cⱼ)]) and the exponential is a degree-8 Taylor polynomial (library exp beyond ENVELOPE_TAYLOR_LIMIT, error < 6e-18).

The scan exists because χ²(c1) need not be unimodal when ξ is far from the truth. It can miss a basin narrower than the grid step; a value outside (c_min, c_max) is reported by exclVolSaturation (−1/+1) and is a diagnostic, not proof of a wrong model. The bounds are a hard window, not a prior, and saturating at them is intended.

Why the tolerance is 1e-8. By the envelope theorem (next section) the gradient is exact only at the exact c1 optimum. For ĉ = c* + δ, F(ξ,ĉ) − F(ξ,c*) = ½F_cc δ² (second order) but ∇_ξF(ξ,ĉ) − ∇_ξF_prof = F_ξc δ (first order). The spurious force does work ΔH = −e·Δw along a trajectory regardless of the step size, so the dual-averaging step size collapses (≈0.6 → 0.001–0.03) and trees grow to 100–1000 leapfrog steps. At 1e-5 six fits ran at the depth limit; the gradient error in whitened coordinates is 1.0–1.5 at 1e-5, 0.02–0.18 at 1e-6 and ≤ 0.007 at 1e-8 (costing ~1.24× per step). The same tolerance is used for the MAP search, its Hessian and every NUTS evaluation.

Gradient

For Φ(ξ, η) maximised over nuisance η, ∇_ξ Φ_prof = ∇_ξΦ(ξ, η*) (envelope theorem; Danskin's theorem extends it to a fixed compact set such as the c1 window, even at the boundary, provided the maximiser is unique; it fails where two basins exchange dominance and the profile has a kink). With residuals rᵢ = yᵢ − m hᵢ − b and pᵢ = wᵢrᵢ,

\[\frac{\partial\ell}{\partial\xi_k}=m\sum_i pI\frac{\partial h_i}{\partial\xi_k},\]

assembled from 15 contractions of the packed Gram columns, T^{(0)}=Σ p G_c, T^{(1)}=Σ p g G_c, T^{(2)}=Σ p g² G_c:

\[\frac{\partial\ell}{\partial\rho_e}=m\Big(-2\sum_i a_iT^{(1)}_{i,ex}+2\rho_eT^{(2)}_{ex,ex}\Big),\qquad \frac{\partial\ell}{\partial\delta\rho_i}=2m\,u_\rho\Big(\sum_j a_jT^{(0)}_{ij}-\rho_eT^{(1)}_{i,ex}\Big)\]

The gradient is a hybrid: one ForwardDiff.gradient! over the whole target (prior, Jacobian, transform), with the likelihood injected through a method of _ll for ForwardDiff duals that evaluates ℓ and g = ∇_ξℓ analytically (_profileLlGrad) and returns a Dual whose partials are Σ_k g_k ∂ξ_k/∂u_j, which is exactly the chain rule. The work vectors are Bumper-allocated (267 → 6 bytes per q point per call). Tested against ForwardDiff at fixed c1 (rtol 1e-7), end to end (within the c1 sensitivity) and against finite differences of the full log density.

Information. After eliminating (m, b) the Fisher information about ξ is m² Jᵀ W^{1/2}(I − P)W^{1/2} J with J_k = ∂h/∂ξ_k and P the projector onto span{h, 1}: a direction is constrained only through the part of J_k orthogonal to {h, 1} (and, with c1 profiled, ∂h/∂c1). ρₑ and c1 act through the same excluded-volume Gram columns and are nearly degenerate; δρ₃ with almost no cavity beads has J ≈ 0 and samples its prior (the report's cavityFrac flags it). Eigenvalues of the information matrix in prior-standardised coordinates run from 1 to 9·10⁵ on the difficult fits.

Profiling is not marginalising

Integrating (m, b) out under a flat prior gives ℓ_marg = ℓ_prof − ½ ln D + ln 2π, an Occam factor that is not invariant to the units of h (a flat prior on m is not flat on m/λ), whereas the profile is invariant under h → λh + β. In the Gaussian approximation both have the same width; they differ in location and shape through the variation of ln D(ξ), which matters in weakly constrained directions. c1 is profiled in both (or sampled, see below). The reported probabilities are posterior probabilities of ξ given the profile construction.

Sampling c1 (fallback for a kinked profile)

With several ligands the likelihood of c1 can have two basins of nearly equal height (SASDVA2, four HEM ligands: c1 ≈ 1.185 and 1.217). The profile ℓ*(ξ) = max_c1 ℓ(ξ, c1) then has a kink where the maximiser jumps, its envelope gradient jumps with it, and NUTS's step size collapses (R̂ 1.75). The scale and the background cannot do this: at fixed ξ and c1 they enter linearly, so their weighted least-squares optimum is unique and smooth; only c1 is nonlinear.

A profiled run therefore asks _c1Kinked (Peaks.jl: two or more prominent interior maxima of the c1 scan, the two highest within C1_KINK_GAP = 3 nats of each other so a branch the sampler would not visit is no kink, in a share of the draws) after the warm-up (whose mass matrix is not adapted yet), when a chain has C1_KINK_DRAWS draws and then every C1_KINK_EVERY draws (each check on at most C1_KINK_DRAWS draws spread over those so far, so it stays cheap), and once more on all of the chain's draws when it ends (a short chain, down to one draw, only then). The first chain that finds a kink stops all of them (KinkDetected), and runModel runs once more with c1 as a fifth sampled parameter: ξ = (ρₑ, δρ₁, δρ₂, δρ₃, c1), c1 ~ Uniform(EXCL_VOL_CORR_BOUNDS) (Distributions.jl), through the same logit as the δρ (c1 = lo + (hi − lo)·σ(t); the prior and the Jacobian leave the standard logistic density in t). There is no profile search and no integral; ∂ℓ/∂c1 is analytic (_dllDc1, the envelope theorem no longer applies at a sampled c1). NUTS does not walk in t itself but in the non-centred shift z = t − t̂(ξ₄), where t̂ is the mode in t of the likelihood times the logistic density given ξ₄ (_c1Centre: Newton from the profiled c1, gradient by the implicit function theorem). The shift has Jacobian 1, so the target is exactly that of the plain five-parameter model, but the narrow, curved ridge that c1 forms with the δρ (plain sampling gave 2.5-20 % divergences on SASDM96 and SASDMC6) becomes a round blob. _ξOfθ and _θOfξ convert between the sampler's coordinates and ξ; stored draws carry the real c1. If that run misses a gate (R̂, ESS or a divergent share of 0.1 % or more) the usual retry fires, longer warm-up and run. Per-draw c1 and χ² are those of the draw. The LOG row c1Kink is true for such a run and false otherwise. If the sampled-c1 run still misses a gate, runModel runs the profiled four-parameter run once without the kink watch (SamplerOptions.watchKink = false) and keeps it when it passes (LOG rows c1KinkFallback, c1KinkProblems). A run that still does not converge walks the retry ladder of runModel (see "The retry ladder" below) before NotConvergedError is thrown (LOG rows ladder, ladderAttempts, ladderRungs, ladderRung). Code: _c1Kinked in profiled-corrs.jl, sampleC1 and the watch in _chainRunner in posterior.jl, the five-parameter methods of Θ, Ξ, logjac in priors.jl.

Priors

δρ_prior(κ_δρ₁₂, κ_δρ₃, ρ̄ₑ) returns LocationScale(L, W, Beta(α, β)) priors. For a Beta with mode m_u and concentration κ = α + β − 2 > 0:

\[\alpha=1+\kappa m_u,\qquad \beta=1+\kappa(1-m_u)\]

  • δρ₁, δρ₂: support [−10, 2] (BOUNDS_δρ₁₂, CRYSOL 3's limits), mode CRYSOL's default 1, m_u = 11/12, α = 1 + 11κ/12, β = 1 + κ/12. At κ = 14: Beta(13.83, 2.17), SD(δρ) ≈ 1.00 (the spread of the Normal(1, 1) it replaced), mean 0.375, median 0.56, P(δρ<0) ≈ 30 %. The mode of a skewed Beta is not its mean. Older single-shell CRYSOL fits in the fixtures report Dro ≈ 0.075–0.083 e·Å⁻³ (δρ ≈ 2.5–2.8), above the upper bound.

  • δρ₃: bounds from φ ∈ [0, φ_max] with ρₑ fixed at the prior mean ρ̄ₑ: L₃ = −ρ̄ₑ/u_ρ, W₃ = φ_max ρ̄ₑ/u_ρ (u_ρ = 0.03), so δρ₃ = (ρ̄ₑ/u_ρ)(φ_max u − 1). Mode at bulk density, m_u = 1/φ_max: α = 1 + κ/φ_max, β = 1 + (1 − 1/φ_max)κ. Defaults κ = 1.25, φ_max = 1.25 give Beta(2, 1.25) on ≈ [−11.1, 2.8]: mean occupancy 0.77, P(φ<1) = 0.73, SD(δρ₃) = 3.3, a deliberately weak prior. Fixing ρ̄ₑ makes the support constant (no coupling to the sampled ρₑ, which would complicate the Jacobian); the implied φ can leave [0, φ_max] by the relative uncertainty of ρₑ (≤ 0.06 % on the buffers checked).

  • ρₑ: ρₑ_prior(pH, σ_pH, solutes; t) takes (μ, σ) from BulkElectronDensity.ρₑ and returns the moment-matched LogNormal (ρₑ > 0 is built in; for small σ/μ it is nearly Gaussian):

    \[\sigma_{ln}^2=\ln\!\big(1+\sigma^2/\mu^2\big),\qquad \mu_{ln}=\ln\mu-\tfrac12\sigma_{ln}^2\]

    The solutes describe the buffer only: never list the measured macromolecule (buffer subtraction has removed it; other copies of it are separate scatterers whose displaced volume only shifts the baseline b absorbs). An empty list is pure water.

_calc_ξ_priors composes the four priors; _ξ₀ draws an initial ξ.

Coordinates

Four coordinate systems appear; confusing them is the commonest mistake.

coordinatesmapused by
ξξ = Ξ(θ)priors, likelihood, reported draws
θ ∈ ℝ⁴θ = μ_θ + σ_θ ⊙ ztransform, Jacobian, target
zz = ẑ + S wL-BFGS, Hessian, Laplace
wwhitenedNUTS, bridge sampling

Only Ξ is nonlinear; the maps θ ↔ z ↔ w are affine with constant Jacobian, so densities in them differ by additive constants that cancel in every ratio (mass ratios, shares).

ξ ↔ θ

Hamiltonian trajectories need an unconstrained space. With σ(t) = 1/(1+e⁻ᵗ):

\[\theta=(a,t_1,t_2,t_3),\quad a=\ln\rho_e,\quad t_k=\mathrm{logit}\frac{\delta\rho_k-L_k}{W_k};\qquad \Xi(\theta)=\big(e^a,\ L_k+W_k\,\sigma(t_k)\big)\]

The density of θ picks up the Jacobian, log π(θ) = log p_ξ(Ξ(θ)) + log J(θ) (omitting it samples p_ξ/J, shifting mass toward the bounds and small ρₑ), with σ' = σ(1−σ):

\[\log J=a+\sum_{k=1}^{3}\big[\ln W_k+\mathrm{loglogistic}(t_k)+\mathrm{loglogistic}(-t_k)\big]\]

evaluated with loglogistic(t) = −log1p(e^{−t}) (t ≥ 0) or t − log1p(e^t) (t < 0), accurate at all t. A Beta prior in logit coordinates becomes

\[\log p_t(t)=\alpha\,\mathrm{loglogistic}(t)+\beta\,\mathrm{loglogistic}(-t)-\ln B(\alpha,\beta)\]

(the ln W_k cancel), which is strictly concave with bounded force α(1−σ) − βσ ∈ (−β, α) and exponential tails e^{−β t}, e^{−α|t|}. The hard bounds therefore never become stiff walls: a likelihood pulling toward a bound meets only this bounded force, and draws pile up against it. With a pull g the balance point is t* ≈ ln(W g/β), at distance ∝ β/(Wg) from the bound, with curvature β independent of g. A pinned posterior is a correct feature of the model. For |t| ≳ 37, δρ rounds to the bound in double precision and the finite-difference Hessian can fail to be positive definite (such an optimum carries no Laplace mass).

The sampled target, up to a constant, is

\[\log\pi(\theta)=-\frac{(a-\mu_{ln})^2}{2\sigma_{ln}^2}+\sum_{k=1}^{3}\big[\alpha_k\,\mathrm{loglogistic}(t_k)+\beta_k\,\mathrm{loglogistic}(-t_k)\big]+\ell(\Xi(\theta))\]

(the +a of the Jacobian cancels the −a of the log-normal density, leaving a Normal in a). It is _lp + _ll + logjac in posterior.jl. The prior part is concave; the likelihood is not (its Hessian is a Gauss–Newton term plus an indefinite residual term, ℓ is a pointwise maximum over c1, and A is quadratic in the contrasts, so the squared residual is quartic and can have several local minima). The posteriors are often multimodal. Modes of π_θ are not modes of p_ξ (they differ by ∇ log J): the L-BFGS optimum and the reported MAP draw are modes of the sampled density.

Standardisation

The coordinates have prior scales differing by orders of magnitude (σ(ρₑ) ~ 10⁻³–10⁻², t of order 1), so θ ↦ z = (θ − μ_θ)/σ_θ with the exact prior moments (θ_prior_moments): a is Normal, and for t = logit u, u ~ Beta(α, β), the cumulant generating function ln Γ(α+s) + ln Γ(β−s) − ln Γ(α) − ln Γ(β) gives

\[\mathbb E[t]=\psi(\alpha)-\psi(\beta),\qquad \mathrm{Var}[t]=\psi_1(\alpha)+\psi_1(\beta)\]

(defaults: shell 2.065 ± 0.812, cavity 0.650 ± 1.357). This equalises marginal prior scales; it does not remove correlations, and the posterior is often far narrower than the prior (σ_z down to ~10⁻⁴ along δρ₁/δρ₂).

Mode search, Laplace approximation and whitening

Stan's windowed adaptation, which AdvancedHMC copies, starts from M⁻¹ = I and shrinks every covariance estimate toward 10⁻³ I with weight 5/(n+5). For a true variance of 10⁻⁸ that regulariser is 10⁴–10⁵ times too large, forcing tiny steps and deep trees all through warm-up. infer therefore first calls _samplingSpace(seed, l):

  1. Multi-start L-BFGS (Optim.jl, memory 10, Hager–Zhang line search) on f(z) = −log π from the seed's ξ₀ and MAP_N_STARTS − 1 further prior draws, then MAP_JITTER_RADII × MAP_JITTER_DIRECTIONS jittered starts around each of at most MAP_JITTER_MAX_OPTIMA optima within MAP_JITTER_WITHIN_NATS of the lowest (radius in posterior sd under that optimum's own Hessian). Many cheap starts (~1 ms each, N = 4) replace one careful one: a basin with hit rate p is missed by K starts with probability (1−p)^K (0.7 % for p = 7.4 %, K = 64; after K misses the 95 % bound on p is 3/K). L-BFGS is needed because the problem is conditioned ~10⁶ in z-space: steepest descent would take ~κ/2 iterations (≈10⁶ against the cap MAP_MAX_ITER = 500) while L-BFGS behaves like a preconditioned method (26 iterations on a toy with the measured spectrum). A start ends at the gradient tolerance MAP_G_TOL, after four consecutive iterations with |Δf| ≤ MAP_F_ABSTOL = 1e-6 (Optim stops when its counter exceeds MAP_F_SUCCESSIVE = 3), or at MAP_MAX_ITER. The f-test exists because near a minimum |∇f| = √(2λ(f−f*)): a gradient of 1e-6 along the stiffest direction (λ = 9·10⁵) is f − f* ≈ 5·10⁻¹⁹, far below anything meaningful. Non-finite values and WLSError count as +Inf; f always has an interior minimum because the Jacobian is included.

  2. Laplace approximation. At a minimum ẑ with Hessian H ≻ 0, π ≈ N(ẑ, H⁻¹) and the mass of the basin is

    \[\mathcal Z_L=\int e^{-f}\,dz\approx e^{-f(\hat z)}(2\pi)^{N/2}\det(H)^{-1/2},\qquad \ln\mathcal Z_L=-f-\tfrac12\sum_i\ln\lambda_i+\tfrac N2\ln 2\pi\]

    with relative error 1 + O(1/λ) (in 1-D the first correction is 1 − f₄/8f₂² + 5f₃²/24f₂³, exact for the Gamma function against Stirling's series). Laplace masses are exactly covariant under affine maps (ratios are unchanged), but the approximation under-weights skewed basins (off by a factor 2 or more) and under-states the width of weakly constrained logit coordinates (δρ₃ of SASDEP6 fit1_model1 and SASDLP4 fit1_model2 come out 2–4× wider; elsewhere σ_z is 0.93–1.5× the Laplace σ_z). They decide where the sampler looks, not how much a region counts.

  3. Hessian by symmetrised central differences of the envelope gradient (2N = 8 gradient evaluations), in two passes: step MAP_HESS_STEP = 1e-4, then MAP_HESS_REL_STEP (0.1) × each coordinate's Laplace σ from the first pass. The truncation error of a column is h²/6 · ∇⁴f and the noise ε_g/h (the gradient error of the c1 tolerance), so the step must scale with σ_i; this is where the 1e-8 tolerance matters most.

  4. H = V diag(λ) Vᵀ, eigenvalues floored at MAP_HESS_EIG_FLOOR = 1 (a ridge, saddle or direction wider than the prior keeps the prior scaling), S = V diag(λ̃)^{−1/2}. The whitening factor, the clustering metric and the basin comparison use the floored eigenvalues; the stored logmass = −f − ½Σ ln λ_i (and so the shares) uses the unfloored ones, and is NaN if any λ_i ≤ 0. The optima are clustered (Mahalanobis distance ≤ MAP_MODE_SEP = 3); the best MAP_OPTIMA_KEPT = 8 are compared by floored Laplace mass, and the heaviest becomes the whitening centre (not necessarily the lowest optimum).

NUTS samples w with θ = μ_θ + σ_θ ⊙ (ẑ + S w) (_θ_of_w), in which the posterior is ≈ N(0, I) and the chain starts at the mode (w₀ = 0). Without flooring Sᵀ H S = I; the whitened Hessian elsewhere measures only the non-Gaussian remainder (condition number ~1–10 instead of 10⁶). Whitening is the choice of the initial HMC metric: HMC with mass matrix M = LLᵀ in x is step-for-step identical to identity-metric HMC in u = Lᵀx. For a leapfrog step on a mode of curvature λ the stable range is ε√λ < 2, and a trajectory needs ~(π/2)√(λ_max/λ_min) steps, which is why the conditioning governs the cost. If no start reaches a finite optimum, ẑ = z₀ and S = I; likewise if the Hessian is non-finite. Draws need no Jacobian to be mapped back; only converting a density does.

Re-whitening. For a Gaussian target f(z) − f(ẑ) ~ ½χ²_N (mean 2, median 1.68 nats for N = 4), so a non-divergent draw more than BASIN_RESTART_NATS = 2 above log π(ẑ) is evidence of a missed basin. The sampler then re-runs the search from that draw, re-whitens there and re-runs the chains, once (rewhitened in the report).

NUTS

infer(...; rngSeed) is reproducible at any thread count, and by default (RNG_SEED = 0) every run is: the UInt64 seed is mixed (SplitMix64) with each draw's purpose and index into that item's own Xoshiro stream (MAP start i, chain k; bridge proposals; the chain-start directions, each under its own purpose tag). The seed's own initial point, the first MAP start, is drawn by seedSampler from a stream of RNG_SEED, so the global RNG plays no part in a run. The seed is the rngSeed row of the run log and of the run sheet; rngSeed = nothing draws a fresh 53-bit seed instead (so a spreadsheet holds it exactly). The MAP search stays serial (threading measured slower, in a validation run now in git history under test/validation/threading/).

Each chain uses multinomial NUTS with the generalised U-turn criterion (as in Stan; max tree depth 10, divergence threshold Δ_max = 1000), a DenseEuclideanMetric(N) (full covariance: the parameters multiply each other in Î, and a diagonal metric would cost ~√((1+r)/(1−r)) more steps for a pair with correlation r), Leapfrog, and StanHMCAdaptor:

  • Dynamics. H(x, p) = U(x) + ½ pᵀM⁻¹p; kick–drift–kick leapfrog is volume-preserving, reversible and symplectic (second order, energy error ≈ O(ε²) bounded within the stability range), so the weights e^{−H} are the whole correction: the next state is drawn from the trajectory with probability ∝ e^{−H} (biased progressive sampling at the top level) and no accept–reject step is needed. The criterion stops when ρ·p♯₋ ≤ 0 or ρ·p♯₊ ≤ 0, ρ the sum of the momenta.
  • Step size. Nesterov dual averaging in log ε (γ = 0.05, t₀ = 10, κ = 0.75, shrinkage point log 10ε₀) toward a tree-averaged acceptance α̅ = mean_leaves min(1, e^{−(H'−H₀)}) of TARGET_ACCEPT = 95 percent. The posteriors are strongly curved and often multimodal; on the 53 fits δ = 0.95 removed the divergences (three fits above 1 % went to ≤ 0.04 %) for 1.3× the steps of Stan's 0.8.
  • Metric windows (nAdapt = 300): ε only for iterations 1–75, covariance windows ending at 100, 150, 250, ε only for 251–300; at each window end the metric becomes n/(n+5) Σ̂ + 10⁻³·5/(n+5) I and dual averaging restarts. The retry (nAdapt = 2000) has windows ending at 100, 150, 250, 450, 850, 1950.
  • Divergences. A subtree diverges when H' − H₀ > 1000 or H' is non-finite. They mark curvature the step cannot follow. A chain is dropped only if it errored or more than CHAIN_MAX_DIVERGENT = 0.5 of its transitions diverged, and a whole run fails (NotConvergedError, checked by runModel with the convergence gate) when MAX_DIVERGENT_RATE = 0.001 (0.1 %) or more of its pooled post-warm-up transitions diverged (owner, 2026-11-16), whatever its R̂ and ESS. Divergent draws are excluded from the MAP and the summaries, and up to HARVEST_DIVERGENT seed the optimum harvest. E-BFMI = Σ(H_t − H_{t−1})² / Σ(H_t − H̄)² ≈ 2(1 − ρ₁) is reported for the worst chain (below ~0.3 the energy random-walks slowly).

Chains, modes and pooling

NUTS chains do not hop between separated modes (the tail probability of a kinetic energy exceeding a barrier ΔU is (1+ΔU)e^{−ΔU}, ≈ 5·10⁻⁴ at 10 nats), so the pooled sample needs an explicit statement of how much each mode counts.

Starts. nChains = N_CHAINS = 8, whatever the thread count. Chains 1 and 2 start at the mode (independent streams: independent ESS in the main mode and a baseline for R̂); chains 3–8 form three mirrored pairs at +r_p û_p and −r_p û_p, r_p ∈ CHAIN_START_RADII = (4, 10, 20) whitened standard deviations (a typical draw is at ≈ 2; a start at r has potential energy r²/2 above the mode), with random directions from a stream of the run seed; both sides matter because the posteriors are skewed against hard bounds. A start with non-finite density or gradient is pulled halfway back, up to eight times. nChains = 1 is exactly one chain, with none of the machinery below.

Optima beyond the search. A basin that attracts almost no random start is missed (SASDX52's third optimum, ~4 % of the Laplace mass, was hit by none of 500 starts). After the first round, L-BFGS is run from a farthest-point cover of HARVEST_COVER = 16 post-warm-up draws (each the draw farthest from those chosen; a 2-approximation of the k-center problem) and up to HARVEST_DIVERGENT = 8 divergent ones, and the optima merged with the search's (100 % recall in the recall study at ≈1.5× the evaluations). An optimum with Laplace share s_k = e^{L_k−L_max}/Σ e^{L_j−L_max} ≥ OPTIMUM_MIN_SHARE = 1 % should have at least OPTIMUM_MIN_CHAINS = 2 chains at it (≥ OPTIMUM_CHAIN_FRACTION of a chain's draws within Mahalanobis radius OPTIMUM_CHAIN_RADIUS = 4, which holds > 99 % of a Gaussian mass in 4-D); the missing ones are started at the optimum, at most OPTIMUM_CHAIN_CAP = 6 extra chains in all (not optima). A chain started at a sparse excursion from the main mode may leave it (SASDX52).

Grouping. chainModes links two chains if the rank-normalised split R̂ of their pair is ≤ MODE_RHAT = 1.25 for the four parameters and log π; a mode is a connected component. Chains in disjoint modes give 1.83 (pair) to 1.66 (many chains), within-mode chains ≈ 1, so 1.25 sits in the gap. There is deliberately no "all-chain R̂ small, so one mode" shortcut.

Bridge sampling. The mass Z_m = ∫_{B_m} π_w dw of each mode (modes.jl, hand-written: BridgeSampling.jl requires Turing, BAT.jl's version is experimental) is estimated by the optimal iterative estimator of Meng and Wong. For draws w₁ᵢ ~ p/Z and proposal draws w₂ⱼ ~ g, with ℓ = p/g and s₁ = N₁/(N₁+N₂), s₂ = 1 − s₁, the bridge function minimising the relative mean-square error is α* ∝ 1/(s₁p + s₂Zg) and gives the fixed-point iteration (unique root)

\[r_{t+1}=\frac{\frac1{N_2}\sum_j \dfrac{\ell_{2j}}{s_1\ell_{2j}+s_2r_t}}{\frac1{N_1}\sum_i\dfrac{1}{s_1\ell_{1i}+s_2r_t}}\ \longrightarrow\ \hat Z\]

g is a Gaussian fitted to one half of the mode's draws and the estimate is made on the other half, both ways round; the mean of the two is log Z_m and half their difference its error in nats. Weights are w_m = softmax(log Z); they are not applied when the bridge error of a mode that could matter exceeds BRIDGE_MAX_ERR = 1 nat (the modes that can matter are then pooled by chain count). Each mode's chains are thinned (drawsPerChain) so the pooled sample carries w_m: with top = max w_m/c_m over live modes, each chain of mode m keeps round(nPost · (w_m/c_m)/top) evenly spaced draws; a mode below MODE_NEGLIGIBLE = 1e-4 keeps none. Convergence is judged on the unthinned draws. Without thinning, the mode share would be the share of chains, which reflects the starts, not the posterior mass. Four fits have a second mode with mass in the chain study (minor shares 4–19 %: SASDKQ8, SASDN32, SASDWZ9, SASDZC6).

Convergence and retry

Within each mode (modes differ by construction), on the unthinned post-warm-up draws, convergence computes (MCMCDiagnosticTools.jl, Vehtari et al. 2021):

  • Split R̂ on 2M half-chains: W the mean within-sequence variance, B the between-sequence variance of means, var⁺ = (n−1)/n W + B/n, R̂ = √(var⁺/W), so R̂² − 1 ≈ τ_μ²/W is the between-mean variance as a fraction of the within variance (1.01 ⇔ means within ≈ 0.14 within-sd). Rank normalisation (Blom scores) makes it location-robust; the folded version (about the median) catches differences of scale and tails; the larger is kept.
  • ESS = S/τ̂, τ = 1 + 2Σρ_t, the autocorrelation from the variogram (ρ̂_t = 1 − (W − γ̄_t)/var⁺) truncated by Geyer's initial positive/monotone pair sequence (max lag 250). A Monte Carlo standard error of a mean is σ/√ESS, of a 16/84 % interval end 1.52σ/√ESS (more in the tails, where the default 2σ interval ends) (a few percent of σ at the default 5600 draws). The tail ESS is the one the intervals stand on; the rule of thumb is R̂ < 1.01 and ESS ≥ 100 per chain.

The worst values over the diagnosed modes are reported (rhatMax flagged when not below RHAT_OK = 1.01, essMin, essTailMin). Convergence and retry: a run counts as converged when its worst R̂ is strictly below RHAT_OK (1.01) and its smallest bulk and tail ESS are strictly above ESS_MIN (400) (every gate is strict, owner 2026-11-16: a value equal to the limit fails); an R̂ or ESS that could not be computed (too few draws, a constant quantity) counts as not converged. Otherwise the whole procedure, warm-up included, is always run once more with RETRY_N_ADAPT = RETRY_N_DRAWS = 2000 and seeds derived by an odd-constant multiplication of rngSeed (RETRY_SEED_OFFSET: a different search, streams and directions, still deterministic), and the run with the smaller worst R̂ is kept (retry = false disables it (a CLI and developer switch); the report's retry line and diagnostics.firstRhat, retryKept say what happened). If the run is still not converged, runModel throws NotConvergedError and nothing is reported (retry = false skips both the rerun and the error). It cannot repair a structural failure (a second mode explored by a single chain keeps R̂ ≈ 1.7). Outcomes: 53/53 at R̂ ≤ 1.01 on the latest run, 8 retries (the validation records were removed; git history under test/validation/rhat_retry/). Convergence statistics detect chains that disagree, not chains that agree on a wrong region.

When a run fails

A run fails (NotConvergedError, no results written, the .LOG of the folder gets status failed and the reasons in its error row) when any of three gates is not passed. Every gate is strict: a value equal to the limit fails.

The retry ladder (a setting)

When the base run, its own longer retry and the sampled-c1 fallback have failed, runModel classifies the failure from the diagnostics of the failed attempt and walks the rungs of that class: each rung is a set of settings that replaces the call's for one more attempt, and the first attempt that passes the gates wins. After every failed attempt the failure is classified again (the class can change), and reruns stop only when one passes or the class the last failure falls into has no unused rung left (each rung runs at most once; there is no fixed cap), and then NotConvergedError lists every attempt. The setting LADDER (keyword ladder) is a map from class to a list of rungs {name?, overrides: {SETTING: value}}.

All thresholds are documented constants of pipeline/run-model.jl, not settings. The collapse step size (about 0.002 on a collapsed run against 0.1 to 0.3 when healthy) is why the stepCollapse threshold sits at 0.01; the mean tree depth alone is no sign of collapse, which is why depth is used only together with a far R̂. The marginal band is R̂ 1.01 to 1.05 and the structural share of divergent transitions is 1.3 to 2 %. ebfmi is not used by the classifier. Every run writes stepSize and stepSizeMin (median and minimum of the pooled chains' adapted step size, LOG and run sheet) and ladderClass, so the thresholds can be checked against the LOGs of any set of runs. Lower TARGET_ACCEPT values raise divergences, which is why 70 and 35 are used only for stepCollapse.

retry = false switches the whole walk off. A rung's CHAIN_START_RADII, RETRY_N_ADAPT and RETRY_N_DRAWS apply only when the caller did not set them, so a script's own values win (SASDMS6's retryNDraws = 8000 stays 8000), and so does a value set to its default. runProject (and so the command line and the TUI) tracks what was set: a keyword or flag, an entry of settings.json or of the model's own settings; it hands the names to runModel as callerSet. A direct call of runModel without callerSet judges by the value instead: one still at its default counts as unset. A map names only the classes it changes (the others keep their default rungs), [] switches a class off, false or "off" every class. The ladder is given like any setting: ladder of runModel, runProject, the terminal interface (the ladder editor) and the command line (--ladder, --model-setting); ladder in settings.json; per model in model-settings.json (or the modelSettings keyword of runProject). Strength, weakest to strongest: default, settings.json, the keywords of the call (the command line), model-settings.json, the modelSettings keyword.

runProject(dir; ladder = "ladder.json")                          # every model
runProject(dir; ladder = (; divergent = []))                      # no divergent rungs
runProject(dir; modelSettings = (; m1 = (; ladder = "off")))      # this model: no ladder

A rung may override only fitting settings (anything that is a keyword of runModel): the ones the ladder uses are TARGET_ACCEPT, CHAIN_START_RADII, RETRY_N_ADAPT, RETRY_N_DRAWS and RNG_SEED_STEP, and SAMPLE_C1 (a ladder-only switch: sample c1 as a fifth parameter); N_ADAPT, N_DRAWS, VAL_SIGMA, N_CHAINS, the OPTIMUM_*, MAP_*, BASIN_RESTART_NATS and HARVEST_* settings are accepted but no default rung uses them. Plot, output, run-level and prior or bound settings (BOUNDS_*, which seedModel reads once) are refused with an InvalidSettingsError naming the rung. The LOG records the class (ladderClass), the attempts (ladderAttempts), the rungs walked (ladderRungs, JSON) and the winner (ladderRung: 0 the base run, i a rung, -1 none).

The ladder below is what we do, in this order, when a fit fails. It comes from fixing the benchmark entries (test/fitting_tests/); the entry named at each step is a real case, and its script carries the setting and a comment saying why. Every setting is a keyword of runModel (a script passes it there; the terminal interface takes it per model in model-settings.json). After any change, check it on three seeds (rngSeed 0, 1, 2): one clean seed is luck, not a fix, and a rate close to a limit is noisy (4 divergent draws in 5600 are 0.07 %).

  1. R̂ or ESS only marginal (R̂ 1.01 to 1.05, ESS a few hundred). Longer chains. The first run is retried once with a longer warm-up and more draws; when even that is marginal, raise retryNAdapt and retryNDraws (for example 6000 and 8000: SASDMS6 needs retryNDraws = 8000). More draws shrink the Monte-Carlo error of R̂ and raise ESS roughly in proportion; they cost only time. This is the first thing to try because it changes nothing about the model.

  2. Chains end in different regions (R̂ far above 1, modes above 1 with low ESS). Start them closer to the optimum with a smaller chainStartRadii (SASDJ66, SASDM86: (2.0, 4.0, 6.0)). The default radii spread the chains widely, which on a flat or curved posterior can leave them in different parts of it for the whole run. Note that the "modes" of a run are clusters of chains: with a tiny step size every chain is its own cluster, so a high mode count is first a sign of poor mixing, not of a multimodal posterior.

  3. Too many divergent transitions (0.1 % or more) with a healthy R̂. Raise the target acceptance δ (TARGET_ACCEPT, a percentage; default 95) to 98 or 99 (SASDVN2, SASDNW9, SASDUP5, SASDMS6, SASDM76, SASDX52). Step-size adaptation aims for a mean acceptance of δ; a higher target means a smaller step. A divergence is the leapfrog integrator going unstable (energy error above 1000), which happens where the curvature is too high for the step (stability needs roughly step < 2/√λ for the largest local curvature λ). A smaller step keeps it stable there. It does not change the target distribution; the price is more leapfrog steps per draw, so a longer run. It only works when the divergences come from the step being too large in a few stiff places: an entry that diverges as often at 99 as at 95 has the structural problem of step 6.

  4. The opposite case: the step size collapses (about 0.002, tree depth 10, R̂ far above 1). On a very stiff or flat, curved posterior the default δ drives the step so small that the chains hardly move. A lower δ (60 for SASDMC6) gives steps about a hundred times larger and the chains mix. Check the divergence rate afterwards: a larger step is the one that can start to diverge, and the 0.1 % gate judges that.

  5. A q cut that leaves too few Shannon channels. A fit to a curve cut at 0.15 to 0.3 Å⁻¹ can end up with only 3 to 4 channels, so the posterior of the four nuisance parameters is nearly flat along curved manifolds that no sampler crosses. Fitting the whole curve (Q_MAX_FIT = Inf; seedModel drops the non-positive bins) removed the problem for SASDVB2 and SASDVC2. Keep a cut only when the data above it really are noise.

  6. A q range that includes noise-dominated points. Divergences that do not respond to δ or the prior can come from fitting points whose signal is below the noise. Cutting at the point where the median I/σ falls to about 2

    removes them. Item 5 is the opposite case, so test both a cut and no cut. Look at the residuals of the fitted grid (lag-1 correlation, runs) before concluding the geometry is at fault.

What does not fix a failed run (measured, do not retry): a different prior width (κ_δρ₁₂, κ_δρ₃), Shannon binning (rebin), removing the HETATM ligands, or a different mass-matrix type (it is already dense). Weakening a gate is not a fix either: the gates are the definition of a run that can be trusted.

Structural failures

A run can keep a divergent share of 1 to 3 % at any δ, with a small adapted step and a shallow tree, so a smaller step does not help. The usual signs are:

  • The gradient is not at fault: the ForwardDiff gradient agrees with a central finite difference to about 2·10⁻⁴ (relative) at divergent and at ordinary draws alike.
  • The c1 bound is not the cause: the divergent draws are not concentrated near it, and the log density shows no kink there.
  • The divergent draws sit in a different part of the posterior than the bulk (a different δρ), spread over all chains, so it is not one stuck chain.
  • The geometry is very stiff: the gradient in θ-space is 10³ to 10⁴ at ordinary draws and the Hessian eigenvalues span many orders of magnitude. The mass matrix is one global matrix learned in warm-up, so where the curvature differs from the average the same step is too large.

What a user can do is limited to the ladder above plus the checks: which parameter the divergent draws share (the draws sheet and the divergent flag), the q range (items 5 and 6 of the ladder), and whether the buffer description (concentrations, uncertainties) is right, since a wrong solvent contrast pushes δρ to its bounds.

Run statistics (the statistics log)

statistics.jl records what each phase of a run computed, as it happens, in a StatBuffer (one per run, kept in the run's StageLog under info["statistics"], locked, no global state): _infer starts an attempt block with statAttempt! and statSettings!, appends the MAP search (statMapSearch!) and, once the chains are pooled, the chain table, the posterior, bounds, axes, correlation, residual, convergence, gate, health and c1 sections and the stage timings (statChains!); infer labels the retry (statLabel!, with the failure class and the ladder rung), and runModel the ladder rungs, the KinkDetected stop and the sampled-c1 restart. statKeep! names the attempt that is the result and why. The buffer is flushed to a scratch file at each phase boundary and whenever it holds statisticsCap(memoryHeadroom) bytes (0.01 % of the forward cache's memory budget, held between 64 KiB and 64 MiB); Pipeline.writeStatistics moves the lines into the run's section of statistics-<ID>.LOG. A recorder that fails writes a statisticsError row and returns: the statistics never fail a run. Nothing replays or re-evaluates the model for the log, and a value that was not recorded is written as unavailable, never as a number. The divergent draws are not in the log (the workbook's divergences sheet has them).

The layout and wording are those of the dev tool bysl fits diagnose. Where that tool replays the model on a grid, the log gives the same lines from the run's own draws, so they are proxies: the axes ratios and kinks are read from the draws binned along the whitened axes (STAT_BIN_MIN draws a bin, a c1 jump is STAT_C1_JUMP); the local λ_max line of nuts is the largest gradient-difference quotient of consecutive draws, a lower bound of the true λ_max (so the stable step size it implies is an upper bound); bounds counts draws near a bound; residuals tests the residuals of the draws' fitted curves (Durbin-Watson and a runs test); the posterior sd in w is compared with the Laplace whitening. The gradient error of the c1 tolerance and the second-pass Hessian are not in the log.

The format is machine-readable. Every section starts with -- <name> -- (an attempt block is --- attempt N: <label> ---); a scalars section is name<TAB>value rows; a table is a tab-separated header and rows, ended by a blank line or the next heading; free text lives only in text sections. STAT_SECTIONS holds this table (the unit test checks the writer against it) and statParse reads a log back.

Draws and summaries

infer returns an Inferred{S,N}: the draws of ξ of the pooled chains, chain after chain (warm-up included; chain, iteration), AdvancedHMC's per-iteration statistics, and for every draw its re-profiled scale, bkgrndCorr, c1, reduced χ² and predicted curve m ĥ(q; ξ, c1) + b on the fitted grid (scale and background are discarded at every density evaluation, so they are recomputed to match). BAYSOL.runModel hands back the same type with the first nAdapt draws dropped.

  • MAP. The reported "MAP" is the non-divergent draw of highest log π (a draw of the sampled density in θ, not the L-BFGS end point and not the mode of the physical-space density). In the Gaussian case the best of S draws has χ²_min median √(8 ln 2/S): ≈ 0.18 posterior sd and 0.016 nats from the mode at S = 5600.
  • Intervals. Quantiles at the percentiles of ±sigma σ of a Normal (default 2σ: 2.28 – 97.72; any finite sigma > 0, with no upper limit) with Julia's linear-interpolation definition, and "bounds", the smallest and largest actual draws inside them. Curve bands apply the same operation at each q: they are pointwise (the whole curve lies inside with probability at most 68 %) bands of the fitted function, not a posterior predictive (which would add σᵢ² and the variance of the nuisance parameters), and should not be compared with the scatter of the data. Divergent draws are removed, which biases the bands slightly narrow.
  • χ² on the measured grid. modelOnRaw interpolates the binned model onto the raw q by a cubic spline (nRaw − 3 degrees of freedom). For a systematic misfit of εσ per raw point and n raw points per bin, the raw χ²_red ≈ 1 + ε² and the binned ≈ 1 + nε²: the binned statistic matches the independent-channel likelihood that is sampled, the measured-grid one is comparable with other programs.

Usage

using BAYSOL
using BAYSOL.MolecularStructure: LocalPathSource, resolveStruct, loadMolecule
using BAYSOL.Hydrogenator: propkaPkas, resolveHydrogens, Propka
using BAYSOL.Scattering: forwardCache
using BAYSOL.BulkElectronDensity: Solute, NonBiological
using BAYSOL.Inference: seedSampler

PH, σ_PH, T_C = 7.5, 0.1, 20.0
SOLUTES = Solute[                       # buffer only: the measured protein is not a solute
    NonBiological(0.200, 0.002, "sodium chloride"),
    NonBiological(0.010, 0.0002, "tris"),
    NonBiological(0.005, 0.0001, "dtt"),
]

path  = resolveStruct(LocalPathSource(pdbPath))
hpath = resolveHydrogens(path, PH; titration = Propka(propkaPkas(path)))
mol   = loadMolecule(hpath)
fw    = forwardCache(mol, qFit, lMax, energy_eV)
seed  = seedSampler(fw, I_fit, σ_fit, PH, σ_PH, SOLUTES; t = T_C)

result = BAYSOL.runModel(seed)
BAYSOL.writeLog(result)
