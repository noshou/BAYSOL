PhysicalConstants

Physical constants and units shared across the package, defined once (PhysicalConstants.jl) so they cannot drift between modules. It is the first module loaded; every other module imports what it needs by name:

# src/PartialMolarVolumes/PMV.jl
using ..PhysicalConstants: AVOGADRO, WATER_MOLAR_MASS

or, from outside the package, using BAYSOL.PhysicalConstants: AVOGADRO.
