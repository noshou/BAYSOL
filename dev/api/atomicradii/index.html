AtomicRadii

Ion/element radius lookup (src/AtomicRadii/AtomicRadii.jl): ion-string parsing, the ionic/charge-state/bare-element fallback chain, and the batch lookup.

BAYSOL.AtomicRadii — Module

Atomic/ionic radii: parse an ion string, then resolve its radius through a fallback chain over the bundled atomic_radii.sqlite3 (loaded once into Dicts). Independent of Molecule.

source
BAYSOL.AtomicRadii.Ion — Type

A parsed ion, e.g. "fe3+" -> Ion("fe", 3).

source
BAYSOL.AtomicRadii._dbpath — Method

Absolute path to the bundled atomic_radii.sqlite3, next to this file.

source
BAYSOL.AtomicRadii._load! — Function

Clear and repopulate the module tables (_IONIC, _ATOMIC, _CHARGES) from the SQLite file, sorting each element's charge list. Called from __init__.

Arguments

  • path: SQLite database file (defaults to _dbpath); must exist.
source
BAYSOL.AtomicRadii.element_radius — Method

Bare-element (radius Å, radius_type) for el, or nothing.

source
BAYSOL.AtomicRadii.ion_key — Method

Ion -> ionic_radii table key, digits-then-sign (Ion("fe", 3) -> "fe3+"). Throws ArgumentError for charge 0.

Arguments

  • ion: parsed ion; ion.charge must be non-zero.
source
BAYSOL.AtomicRadii.ion_radius — Method

Ionic radius (Å) for an ionic_radii key, or nothing.

source
BAYSOL.AtomicRadii.lookup — Method

Batch resolve_one: resolve each ion/element string to a radius in Å, or nothing if unknown. Input order and count preserved, repeats deduped per call. Each entry pairs the input string with its radius or nothing.

Arguments

- `ions`: ion/element strings to resolve, e.g. ["fe3+", "o2-", "fe"].

Returns

  • Vector{Tuple{String,Union{Float64,Nothing}}}, one entry per input.
source
BAYSOL.AtomicRadii.nearest_ion — Method

Ion key for the on-file charge state of element closest to charge; nothing if the element has no charge states on file.

Arguments

  • element: bare element symbol, lowercase.
  • charge: desired signed charge.
source
BAYSOL.AtomicRadii.resolve_one — Method

Resolve one ion/element to a radius (Å) via the fallback chain: exact charge match, else nearest charge state, else bare element, else nothing. Unparseable strings go straight to the bare-element table.

Arguments

  • ion: ion or bare-element string.
source
BAYSOL.AtomicRadii.tryparse_ion — Method

Parse an ion string like "fe3+" or "fe+3"; nothing for a bare element like "fe" or an unparseable string.

Arguments

  • s: element then optional magnitude/sign, in either order.
