AtomicRadii

Ion/element radius lookup (src/AtomicRadii/AtomicRadii.jl): ion-string parsing, the ionic/charge-state/bare-element fallback chain, and the RadiiSource lookup contract.

BAYSOL.AtomicRadii — Module

Atomic/ionic radii: parse an ion string, then resolve its radius through a fallback chain over the bundled atomic_radii.sqlite3 (loaded once into Dicts). Independent of Molecule.

BAYSOL.AtomicRadii._resolve_all — Method
_resolve_all(ions::AbstractVector{<:AbstractString}) -> Vector{Tuple{String,Union{Float64,Nothing}}}

Batch resolve_one; input order and count preserved, repeats deduped per call. Each entry pairs the input string with its radius (Å) or nothing.

Named apart from lookup so that this plain function stays independent of any particular RadiiSource; the lookup method below is a thin wrapper over it for AtomicRadiiSource specifically.

Arguments

- `ions`: ion/element strings to resolve.

BAYSOL.AtomicRadii.lookup — Function
lookup(src::RadiiSource, ions) -> Vector{Tuple{String,Union{Float64,Nothing}}}

Resolve each ion/element string to a radius in Å, or nothing if unknown. One entry per input, in input order.

Arguments

  • src: the radii backend to query.
  • ions: ion/element strings, e.g. ["fe3+", "o2-", "fe"].

BAYSOL.AtomicRadii.resolve_one — Method
resolve_one(ion::AbstractString) -> Union{Float64,Nothing}

Resolve one ion/element to a radius (Å) via the fallback chain: exact charge match, else nearest charge state, else bare element, else nothing. Unparseable strings go straight to the bare-element table.

Arguments

  • ion: ion or bare-element string.
