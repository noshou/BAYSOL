Runtime

The process machinery the others run on (src/Runtime/): thread-safe memoization, per-stage timing and garbage-collector pausing.

Runtime

BAYSOL.Runtime — Module

The process machinery the rest of the package runs on: thread-safe memoization, per-stage timing and garbage-collector pausing. Each is re-bound at the package root (BAYSOL.Cache, …). Loaded after Utils: Timing imports NS_PER_S from PhysicalConstants.

source

Cache

BAYSOL.Runtime.Cache — Module

Thread safe caching primitives.

source
BAYSOL.Runtime.Cache.KeyedCache — Type
KeyedCache{K,V}()

A thread-safe keyed memoization cache: a Dict{K,V} guarded by one ReentrantLock. K/V stay concrete type parameters (never Any) so Base.get! specializes like a bare Dict lookup would.

source
BAYSOL.Runtime.Cache.Lazy — Type

A cache of a value of type T, built unforced as Lazy{T}(f) from a zero-arg thunk f; f runs once, on the first force. done is atomic, so the common already-built case reads the value without taking the lock.

source
BAYSOL.Runtime.Cache.force — Method

Run c's thunk once, under its lock, then return the stored value on every call.

Arguments

- `c`: the cache to force.
source
Base.get! — Method

Return the cached value for key, computing it via the zero-arg thunk f and storing it on the first miss. The lookup, compute-on-miss, and store are all done under c's lock, so concurrent callers racing on the same missing key never double-store or observe a torn Dict.

Arguments

  • f: zero-arg thunk, run only on a cache miss for key.
  • c: the cache to look up/store into.
  • key: the lookup key.
source
Base.haskey — Method

Whether key has already been memoized in c, taken under c's lock.

Timing

BAYSOL.Runtime.Timing — Module

Named stage of a run, for the report's === Timing === section. A StageLog is created when a run starts and is handed down to whatever should be timed; everything is a no-op when the log is nothing.

source
BAYSOL.Runtime.Timing.Stage — Type

One timed stage. group is :static, :sampling or :report; depth 1 is a direct child of its group, 2 a child of the preceding depth-1 stage, and so on. compile and gc are the seconds of seconds spent compiling and in GC. note is free text printed next to the name (e.g. [cache hit]).

source
BAYSOL.Runtime.Timing.StageLog — Type

Stages in execution order (a parent precedes its children), the start time of the run (t0, time_ns(); compile0, the compile counter then), and free-form run facts (info, e.g. lMax, n_samples).

source
BAYSOL.Runtime.Timing.fmt_count — Method

A count for the timing report: plain below 1000, else thousands with up to two decimals and no trailing zeros (2000 → 2k, 14210 → 14.21k, 1500 → 1.5k).

source
BAYSOL.Runtime.Timing.stage_seconds — Method

Total (seconds, compile, gc) of a group's depth-1 stages.

source
BAYSOL.Runtime.Timing.tick — Method

A snapshot of the clock, JIT-compile and GC counters. See tock!.

source
BAYSOL.Runtime.Timing.timed! — Method

Run f(), recording it as a stage, and return its value. The stage is reserved before f runs, so stages f itself records sit after it (as its children).

source
BAYSOL.Runtime.Timing.tock! — Method

Append the stage that began at t =tick() and ends now, and return its (seconds, compile, gc). A parent stage is pushed before its children by timed!; with tick/tock! push order is finish order.

GCPause

BAYSOL.Runtime.GCPause — Module

Pausing Julia's garbage collector around the allocation-heavy stretches of a fit, with a byte budget so memory stays bounded.

Julia collects whenever the heap has grown by an adaptive amount, and with a small live heap and large temporary arrays (the Y_lm blocks of the static build) that is often: GC was a fifth of the wall clock of the fitting tests. with_gc_paused turns automatic collection off for the duration of a call (re-entrant: pauses nest and the collector comes back on when the outermost one ends, also on an exception, and only if it was on before), and gc_checkpoint, called in the loops that allocate, runs one cheap young collection (GC.gc(false)) once the live heap has grown past the budget since the last one. So garbage piles up at most budget bytes beyond the live data, and is cleared in a few large young collections rather than many small ones.

source
BAYSOL.Runtime.GCPause.GC_PAUSE_BUDGET — Constant

Default byte budget of with_gc_paused: garbage allowed to pile up before a checkpoint collects it (1 GiB).

source
BAYSOL.Runtime.GCPause.gc_checkpoint — Method

Inside with_gc_paused: if the live heap has grown by more than the budget since the last collection, runs one young collection (GC.gc(false)) and resets the baseline. Does nothing otherwise, and nothing outside a pause. Cheap enough (atomic reads and a compare) to call once per iteration of a hot loop. Safe from several threads: the collection runs under the pause lock (a thread that finds it taken skips, the holder is collecting for everyone), so a pause ending concurrently cannot leave the collector off.

source
BAYSOL.Runtime.GCPause.with_gc_paused — Method

Runs f() with automatic garbage collection off, and returns its value.

Pauses nest (a depth counter, under a lock): the collector is switched off by the outermost call and back on, if it was on before, when that call ends, whether f returned or threw. Nested calls keep the smallest budget given.

Arguments

  • f: a zero-argument function.

Keywords

  • budget::Integer = GC_PAUSE_BUDGET: bytes of heap growth that gc_checkpoint tolerates before collecting.

Returns

  • Whatever f() returns.
