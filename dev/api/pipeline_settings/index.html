Pipeline: settings

The tunable constants of the pipeline (params.jl: sample counts, retry and plot defaults, and the data and structure settings Q_MIN, Q_MAX, SIGMA_SCALE, EXCLUDE_Q, LMAX, CHAINS, MODEL, ADD_HYDROGENS) and the settings as keywords (settings.jl: seedKeywords, runKeywords, runArguments, resultsKeywords, the setting tables, the checks of a value and InvalidSettingsError). The settings file, the buffer of a project and the run of a project folder are the terminal interface's (tui/src/store/), not part of this module. They configure the calls on Pipeline: entry points and Pipeline: results and figures.

BAYSOL.Pipeline.ADD_HYDROGENS — Constant

Whether seedModel adds hydrogens (PROPKA and pdb2pqr). false fits the structure as it is, with the hydrogens it carries. Which tool and force field do it is not a setting.

source
BAYSOL.Pipeline.CHAINS — Constant

The chains of the structure that seedModel keeps, ("A", "B"): one character each, as written in the file (case counts); every other chain is removed before the hydrogens are added. The default, (), keeps every chain.

source
BAYSOL.Pipeline.EXCLUDE_Q — Constant

Ranges of q, in Å⁻¹, ((q_lo, q_hi), ...), whose points seedModel leaves out (both ends included), for instance a few points a detector artefact spoiled. The default, (), leaves none out. Each range needs 0 ≤ q_lo < q_hi; they may overlap.

source
BAYSOL.Pipeline.FIGURES_COMPILE — Constant

Default compile of results: run a LaTeX engine on the .tex figures (about a second per figure; needs lualatex, xelatex or pdflatex, and poppler for PNG/SVG). Off by default, and a failed run is a warning.

source
BAYSOL.Pipeline.FIGURES_COMPILER — Constant

Default latexCompiler of results: the path of the LaTeX compiler that compile = true runs (lualatex, xelatex or pdflatex, named by its file name), a path; "" (the default) looks for lualatex, then xelatex, on the PATH. The terminal interface's "compile plots" uses the same setting; a path that is set is never replaced by another compiler.

source
BAYSOL.Pipeline.FIGURES_DIR — Constant

Default plotDir of results: the folder the .tex figures are also copied to, a path; "" (the default) copies nothing. The terminal interface shows it as the "plot dir": when it is empty it moves and compiles plots into the plots folder of its own data folder, one folder for all projects, as <plot dir>/<project>/<run>/<model>/. A run made by runProject copies the figures of each model into that layout.

source
BAYSOL.Pipeline.FIGURES_FORMATS — Constant

Default formats of results when compile is on: the file types made from each .tex, any of :pdf, :png, :svg.

source
BAYSOL.Pipeline.FIGURES_TEX — Constant

Default tex of results: write each figure as a standalone pgfplots .tex file in the output folder's plots/ (LaTeX is not needed for this).

source
BAYSOL.Pipeline.LMAX — Constant

The spherical-harmonic band limit of the forward model that seedModel pins (lMax). nothing, the default, is automatic: ⌈qMax·D⌉ for the largest fitted q and the diameter D of the scatterer cloud. A value at least 1 is used as it is (a low one is a coarser, faster model; a high one costs time).

source
BAYSOL.Pipeline.MODEL — Constant

Which model of a multi-model structure (an NMR ensemble) seedModel uses: the MODEL-th in the file, counting from 1. The default, 1, is the first model whatever its number, which is what was always read.

source
BAYSOL.Pipeline.N_ADAPT — Constant

Default warm-up of runModel: NUTS iterations of step-size and mass-matrix adaptation, discarded from the posterior.

source
BAYSOL.Pipeline.N_DRAWS — Constant

Default number of posterior draws of runModel, after the N_ADAPT warm-up iterations.

source
BAYSOL.Pipeline.PLOT_AXIS_LW — Constant

The line width (pt) of the axis lines (the box round each figure).

source
BAYSOL.Pipeline.PLOT_BORDER_PT — Constant

The padding (pt) the PDF page keeps round a figure. Without it the page is cropped to the figure's bounding box and the edge of a label or a tick at the right or the top is cut off.

source

source

Colour of the posterior bounds band of the I(q) plot.

source
BAYSOL.Pipeline.PLOT_COLOUR_BAND_RESID — Constant

Colour of the posterior bounds band of the residuals plot.

source
BAYSOL.Pipeline.PLOT_COLOUR_DATA — Constant

Colour of the measured points.

source
BAYSOL.Pipeline.PLOT_COLOUR_ERRORBAR — Constant

Colour of the measured points' error bars.

source
BAYSOL.Pipeline.PLOT_COLOUR_HIST — Constant

Colour of the histogram bars.

source
BAYSOL.Pipeline.PLOT_COLOUR_MAP — Constant

Colour of the MAP curve and of the MAP marker of the histograms.

source
BAYSOL.Pipeline.PLOT_COLOUR_POSTERIOR — Constant

Colour of the posterior quantile curves.

source
BAYSOL.Pipeline.PLOT_COLOUR_REFERENCE — Constant

Colour of the reference curve (CRYSOL, FoXS, … ) on a comparison plot.

source
BAYSOL.Pipeline.PLOT_COMPARE — Constant

Whether runProject also makes the combined comparison figure of a run (compareResults: the measured curve, the fitted curve of every model and the reference curves of the project's reference-fit/ folder, on one plot, and the compare workbook with the same curves). It is made after the last model, in the run's compare/ folder, when at least one model was fitted.

source
BAYSOL.Pipeline.PLOT_COMPARE_COLOURS — Constant

The colours of the fitted curves of the comparison figure, in order: the first model has the first colour, the second the second, and so on, starting again from the first when there are more models than colours. Each is a colour name or a colour code (see PLOT_COLOUR_MAP); the default is the Okabe-Ito set, which stays distinguishable with the common forms of colour blindness. At least one colour.

source
BAYSOL.Pipeline.PLOT_COMPARE_MARKERS — Constant

The markers of the reference curves of the comparison figure, in order: the first reference has the first marker, and so on, starting again when there are more references than markers (all references share the colour PLOT_COLOUR_REFERENCE, so the marker tells them apart). Each is one of PLOT_MARKER_NAMES. At least one marker.

source
BAYSOL.Pipeline.PLOT_FONT — Constant

The default font of PlotStyle: the (text font, math font) pair (PLOT_TEXT_FONT, PLOT_MATH_FONT).

source
BAYSOL.Pipeline.PLOT_HIST_BINS — Constant

Bins of each posterior histogram.

source
BAYSOL.Pipeline.PLOT_LINMIN_TICKS — Constant

The number of minor ticks between two major ones of a linear axis (a log axis has its own).

source
BAYSOL.Pipeline.PLOT_LW_COMPARE — Constant

Line width (pt) of the fitted curves of the comparison figure.

source
BAYSOL.Pipeline.PLOT_LW_ERRORBAR — Constant

Line width (pt) of the error bars.

source
BAYSOL.Pipeline.PLOT_LW_MAJOR_TICK — Constant

The line width (pt) of the major axis ticks.

source
BAYSOL.Pipeline.PLOT_LW_MAP — Constant

Line width (pt) of the MAP curve and of the histograms' MAP marker.

source
BAYSOL.Pipeline.PLOT_LW_MINOR_TICK — Constant

The line width (pt) of the minor axis ticks.

source
BAYSOL.Pipeline.PLOT_LW_QUANTILE — Constant

Line width (pt) of the quantile curves of the I(q) plot.

source
BAYSOL.Pipeline.PLOT_LW_QUANTILE_RESID — Constant

Line width (pt) of the quantile curves of the residuals plot.

source
BAYSOL.Pipeline.PLOT_LW_REFERENCE — Constant

Line width (pt) of the reference curve.

source
BAYSOL.Pipeline.PLOT_LW_ZERO_LINE — Constant

Line width (pt) of the zero line of the residuals plot.

source
BAYSOL.Pipeline.PLOT_MARKERSIZE — Constant

Radius (pt) of the data markers.

source
BAYSOL.Pipeline.PLOT_MARKER_NAMES — Constant

The marker names a PLOT_COMPARE_MARKERS may hold: the names of the pgfplots marks (a name ending in * is the filled mark). The terminal plot draws the closest mark UnicodePlots has.

source
BAYSOL.Pipeline.PLOT_MATH_FONT — Constant

The math font of the figures: a fontspec name, TeX Gyre Pagella Math (the TeX Live package tex-gyre-math), the companion of PLOT_TEXT_FONT.

source
BAYSOL.Pipeline.PLOT_PREVIEW_SIZE — Constant

Width (characters) and height (rows) of a terminal plot.

source
BAYSOL.Pipeline.PLOT_TEXT_FONT — Constant

The text font of the figures: a fontspec name, TeX Gyre PagellaX (the TeX Live package newpx). Any font that LuaLaTeX can find does; fontAvailable says whether it can find one, and bysl plots fonts does the same from the shell.

source
BAYSOL.Pipeline.PLOT_TICK_COLOUR — Constant

The colour of the axis ticks, major and minor, and of the stubs that carry the x tick labels; a ColorSpec like the other colours.

source
BAYSOL.Pipeline.PLOT_TICK_LENGTH_CM — Constant

The length (cm) of a major tick; a minor tick is half as long. The ticks point inward and are drawn on all four sides of the axis.

source
BAYSOL.Pipeline.PLOT_TUI_SIZES — Constant

The sizes of the terminal plots a :tui run writes besides plots.txt (which keeps PLOT_PREVIEW_SIZE): an ordered list of (width, height) pairs, the width in terminal columns of the WHOLE plot (the axis labels, ticks and legend included, so the widest line of the text is at most that wide) and the height in rows of the plot area (the title, the axis and the legend come on top, about 5 rows more; a histogram has that many bins). A text plot cannot be resized afterwards, so a viewer picks the largest one that fits its window. Each size is written for every model and for the comparison as plots_<width>x<height>.txt next to plots.txt. At least one size; each at least (24, 3) and at most (400, 100), and each larger than the one before in both width and height.

source
BAYSOL.Pipeline.PLOT_WHISKERWIDTH — Constant

Length (pt) of an error bar's whisker.

source
BAYSOL.Pipeline.PLOT_WIDTH_HEIGHT_CM — Constant

(width, height) in cm of every figure: the I(q) plots, the residuals plot, the comparison plot and each posterior histogram all have exactly this size. 16 cm is the text width of an A4 page with 25 mm margins and of a US Letter page with 1 in margins (16.5 cm), so a figure fits either at full width; the height is 3:2.

source
BAYSOL.Pipeline.PLOT_XTICK_ANGLE — Constant

The angle (degrees, counter-clockwise) the x tick labels of every figure are turned by, so that long labels (0.3405, 6×10⁻⁶) do not run into each other: they end at their tick and slope up to the left. 0 leaves them horizontal.

source
BAYSOL.Pipeline.PLOT_XTICK_LABEL_PAD_PT — Constant

The gap (pt) between the end of an x tick (its bent leader) and its label; the label's inner sep.

source
BAYSOL.Pipeline.PLOT_XTICK_STUB_PT — Constant

The length (pt) of the straight stub that carries an x tick out of the axis, and of the elbow (pt) that then bends towards the slanted label; see PLOT_XTICK_ANGLE.

source
BAYSOL.Pipeline.PLOT_YLIM_LIN_PAD_FRAC — Constant

The residuals plot's y-padding, as a fraction of the residuals' range.

source
BAYSOL.Pipeline.PLOT_YLIM_LOG — Constant

The I(q) plots' y-range is the data's range scaled by these factors (the plot is centred on the data, not on however far the error bars or the band extend).

source
BAYSOL.Pipeline.PLOT_YTICK_LABEL_PAD_PT — Constant

The gap (pt) between the y axis and its tick labels.

source
BAYSOL.Pipeline.Q_MAX — Constant

The highest q, in Å⁻¹, of the curve that seedModel fits (see Q_MIN). nothing, the default, is no upper limit. Must lie above Q_MIN when both are given. Points at Q_MAX are kept.

source
BAYSOL.Pipeline.Q_MIN — Constant

The lowest q, in Å⁻¹, of the curve that seedModel fits: points below it are left out (before the Shannon binning, so the channels and lMax follow the range that is fitted). nothing, the default, is no lower limit: every point is used. Points at Q_MIN are kept.

source
BAYSOL.Pipeline.SETTING_CHOICES — Constant

The settings above that hold some of a few fixed choices (any subset, in this order), read by the terminal interface, which shows them as tabs to switch on and off (dev/scripts/harvest-defaults.jl copies them to default_settings.json). A setting of kind :markers (PLOT_COMPARE_MARKERS) is the exception: its choices are the names a marker may have, and it is an ordered list, not a subset (see SETTING_KINDS).

source
BAYSOL.Pipeline.SETTING_KINDS — Constant

The kind of the settings whose kind cannot be read off the default: :optionalFloat and :optionalInt (a number, or nothing for "not given"; nothing has no type of its own), :ranges (a list of (low, high) pairs of q), :strings (a list of texts), :colours (an ordered, non-empty list of colours, a colour name or #rrggbb each; a colour may be repeated) and :markers (an ordered, non-empty list of marker names from the setting's SETTING_CHOICES; a name may be repeated) and :sizes (an ordered, non-empty list of [width, height] pairs of whole numbers, each larger than the one before in both) and :path (a text for a file or folder path, which may be empty for "not set"; no control characters, at most 4096 characters). Every other setting has the kind of its default (settingKind).

source
BAYSOL.Pipeline.SETTING_LIMITS — Constant

The limits of each setting above that has one, read by the terminal interface when a user edits a value (dev/scripts/harvest-defaults.jl copies them to default_settings.json). Each limit is above or below (strict) or atLeast or atMost (inclusive). They follow results' check of a PlotStyle: widths, sizes and paddings are not negative. The settings that are tuples are left out.

source
BAYSOL.Pipeline.SETTING_NAMES — Constant

The constants above that are settings, the ones a user may change: the terminal interface shows each on a page of its own, and loadSettings accepts a saved value for these and for no other name.

source
BAYSOL.Pipeline.SETTING_PARTS — Constant

The name of each part of the tuple settings above, in order, which the terminal interface shows beside the part when a user edits it. A setting that is a tuple has exactly one name for each of its parts (a named tuple's parts are named by its keys, in their order).

source
BAYSOL.Pipeline.SETTING_RELATIONS — Constant

The rules that tie settings above together, or that a tuple setting must obey, which a set of values must obey as a whole; each is a (rule, setting, ...) and is read by the terminal interface and by loadSettings. :belowSetting: setting is below the setting of (skipped when either is nothing); :allAbove: every number of setting is above bound; :ordered: the pair setting has its first number below its second, and above above if there is one; :opacity: setting is a (colour, opacity) pair whose opacity is in 0 to 1.

source
BAYSOL.Pipeline.SIGMA_SCALE — Constant

The factor seedModel multiplies the measured standard errors by, before anything else is done with the curve (binning included). 1, the default, leaves them as they are; a value above 1 says the errors were under-estimated, below 1 over-estimated. Must be above 0. A run records it.

source
BAYSOL.Pipeline.TABLE_DIR — Constant

Default tableDir of runProject: the folder the workbooks and the comparison table of a run (<model>.xlsx, compare.tsv) are also copied to, a path; "" (the default) copies nothing. The terminal interface shows it as the "data dir": when it is empty it moves data into the data folder of its own data folder, one folder for all projects. A file whose name is taken there gets -2, -3, ... and never replaces another.

source
BAYSOL.Pipeline.TABLE_SIGFIGS — Constant

Significant figures of every number in the tables of results: a workbook cell is rounded to this many. The default, 17, is every bit of a Float64 (the number reads back exactly); lower it for shorter files or to drop the noise in the last digits (15 is the most a Float64 is guaranteed to carry).

source
BAYSOL.Pipeline.VAL_SIGMA — Constant

Half-width, in σ, of the default posterior interval of runModel: the "quantiles"/"bounds" entries are built from the empirical quantiles that bound the central interval a Normal distribution would have at ±VAL_SIGMA σ (2σ: the 2.28th and 97.72nd percentiles). The quantiles are those of the draws, so the interval is no assumption of a Normal posterior; the σ only says which percentiles. The run sheet records them.

source
BAYSOL.Pipeline.SETTING_KEYWORDS — Constant

SETTING_KEYWORDS: for each of the settings of settings.json the keyword (and entry point) that carries it when a run is made from code, as (setting, keyword, entry, check) rows. Every setting is here: seedModel takes the geometry, hydration-shell, prior and c1 settings, the data (q range, error scale, excluded ranges) and the structure (chains, model, hydrogens, lMax), runModel the sampler, MAP-search and output-interval settings, results the table and figure settings (the plot look as a style built from the PlotStyle fields named here). seedKeywords, runKeywords and resultsKeywords read it, and so does runProject. entry is :seedModel, :runModel, :results, :runModelArgs (the positional nSamples/nAdapt of runModel), :runProject (a keyword of runProject alone: plotCompare) or :PlotStyle; check says that the keyword is validated with the checks of loadSettings (the keywords that are new since the settings had no keyword).

source
BAYSOL.Pipeline._MAX_PATH_LENGTH — Constant

The most characters a :path setting holds.

source
BAYSOL.Pipeline.InvalidSettingsError — Type

The error loadSettings throws when settings.json cannot be read or holds an invalid value, and that seedModel, runModel, results and runProject throw for a keyword that stands for a setting (mapNStarts, shellSample, ...) and is out of its limits: the same checks, the same lines. problems has a line for each, naming the setting; hint is the sentence that ends the message (what to do about it).

Exceptions

This type is the exception; the fit that asked for the settings must not go on.

source
BAYSOL.Pipeline._applyKeywords! — Method

Overrides, in settings (a Dict from loadSettings), the settings that the keywords in given carry: given is a NamedTuple of keyword => value from runProject, where nothing means "take the setting" and so does :settings. A setting that may be nothing (Q_MIN, Q_MAX, LMAX: no limit, automatic) is cleared with a nothing given for it, and only :settings takes the saved one. The function works on any NamedTuple of keywords, so overrides of one model can be applied the same way to a copy of settings. Every given value is checked as loadSettings checks its setting, and the rules between settings are checked on the result; settings is changed only if all pass.

Exceptions

  • InvalidSettingsError with a line for each problem.
  • KeyError for a keyword of given that no setting stands for.
source
BAYSOL.Pipeline._chainId — Method

A chain id of a :strings setting: one character that is not blank or a control.

source
BAYSOL.Pipeline._checkedKeywords — Method

The keywords of entry (:seedModel, :runModel or :results) in kw, a NamedTuple of the values a caller passed for the checked keywords of that entry point, each checked as loadSettings checks the setting of the same name: its type, limits and, for the settings that depend on each other (MODE_δρ₁₂ inside BOUNDS_δρ₁₂, SASA_N_OCC at most SHELL_SAMPLE, ...), the rules of SETTING_RELATIONS.

Returns

  • kw with every value in the type of the setting's default (an Int, a Float64, a Tuple).

Exceptions

  • InvalidSettingsError, with a line SETTING = value: what is wrong for each problem, the lines loadSettings reports.
source
BAYSOL.Pipeline._checkedValue — Method

The value v of the setting name, in the type its default has; or an ArgumentError saying what is wrong. The limits are checked here too.

source
BAYSOL.Pipeline._isColour — Method

Whether x is a colour a figure can use: a name or a code colourRgb reads.

source
BAYSOL.Pipeline._isNullable — Method

Whether the setting name may hold nothing (no limit, automatic).

BAYSOL.Pipeline._keywordRows — Method

The rows of SETTING_KEYWORDS of the entry point entry.

source
BAYSOL.Pipeline._keywords — Method

source
BAYSOL.Pipeline._mergedRelations — Method

BAYSOL.Pipeline._mergedTable — Method

BAYSOL.Pipeline._plotStyle — Method

source
BAYSOL.Pipeline._settingNames — Method

The names of all the settings (the SETTING_NAMES of every module).

source
BAYSOL.Pipeline._settingOwner — Method

The module whose params.jl defines the setting name.

source
BAYSOL.Pipeline._sizeValue — Method

A (width, height) pair of a :sizes setting, within PLOT_TUI_SIZE_LIMITS, or an error.

source
BAYSOL.Pipeline._tuplePart — Method

One part of a tuple setting, shaped like the default part d; the part, or an error.

source
BAYSOL.Pipeline._tupleValue — Method

The tuple setting value v, shaped like the default default; the value, or an error.

BAYSOL.Pipeline.resultsKeywords — Method
resultsKeywords(settings) -> NamedTuple

The keywords of results that settings stand for: tableSigfigs (TABLE_SIGFIGS), tex (FIGURES_TEX), compile (FIGURES_COMPILE), formats (FIGURES_FORMATS), plotDir (FIGURES_DIR), latexCompiler (FIGURES_COMPILER), plotTuiSizes (PLOT_TUI_SIZES) and style, the PlotStyle the PLOT_* settings describe (each is the field of the same meaning; the font is the pair PLOT_TEXT_FONT, PLOT_MATH_FONT). With the default settings style is PlotStyle().

Returns

  • A NamedTuple of the eight keywords.

Exceptions

  • KeyError if settings lacks one of the settings.
source
BAYSOL.Pipeline.runArguments — Method
runArguments(settings) -> NamedTuple

The two positional arguments of runModel that settings stand for: (nSamples = N_ADAPT + N_DRAWS, nAdapt = N_ADAPT). Pass them with runModel(seed, runArguments(settings)...; runKeywords(settings)...).

Returns

  • (nSamples, nAdapt), both Int.

Exceptions

  • KeyError if settings lacks N_ADAPT or N_DRAWS.
source
BAYSOL.Pipeline.runKeywords — Method
runKeywords(settings) -> NamedTuple

The keywords of runModel that a setting stands for, from settings: sigma (VAL_SIGMA), δ (TARGET_ACCEPT), rngSeed, nChains, retryNAdapt, retryNDraws, chainStartRadii, optimumChainCap, optimumMinChains, optimumChainRadius, optimumChainFraction, mapMaxIter, mapNStarts, mapFSuccessive, mapOptimaKept, mapJitterRadii, mapJitterDirections, mapJitterMaxOptima, mapJitterWithinNats, basinRestartNats, harvestCover and harvestDivergent. Pass it on with runModel(seed, runArguments(settings)...; runKeywords(settings)...).

Returns

  • A NamedTuple of the 22 keywords.

Exceptions

  • KeyError if settings lacks one of the settings.
source
BAYSOL.Pipeline.seedKeywords — Method
seedKeywords(settings) -> NamedTuple

The keywords of seedModel that a setting stands for, from settings (what loadSettings returns): thickness (SHELL_THICKNESS), probe (PROBE_RADIUS), κ_δρ₁₂, κ_δρ₃, pmvFallbackUncert (PMV_FALLBACK_UNCERT), bounds_δρ₁₂, mode_δρ₁₂, φ_max, exclVolCorrBounds (EXCL_VOL_CORR_BOUNDS), exclVolCorrEps, shellAreaPerPoint, shellMinPoints, shellSample, sasaNOcc, beadRayRange, beadRayDirs, qMin, qMax, sigmaScale, excludeQ, lMax (LMAX), chains, model and addHydrogens (the lower-case name of the setting where none is given). Pass it on with seedModel(...; seedKeywords(settings)...). The sampler settings are runKeywords, the output and plot settings resultsKeywords; every setting is a keyword of one of the three, and settings.json is one way, not the only one, to supply them.

Returns

  • A NamedTuple of the 24 keywords.

Exceptions

  • KeyError if settings lacks one of the settings (a Dict from loadSettings has them all).
source
BAYSOL.Pipeline.settingKind — Method

The kind of the setting name whose default is v: :bool, :int, :float, :colour, :font, :set (some of the choices of SETTING_CHOICES), :tuple, or one of the kinds of SETTING_KINDS that a default cannot tell (:optionalFloat, :optionalInt, :ranges, :strings, :colours, :markers, :sizes, :path).
