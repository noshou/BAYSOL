BAYSOL_Utils

BAYSOL.BAYSOL_Utils.Constants.BOND_CUTOFF — Constant

Covalent-bond distance cutoff, Å: generous enough for P-O (~1.5-1.6 Å) and C-O/C-C/C-N (~1.4-1.6 Å) single bonds, tight enough to exclude non-bonded contacts. Molecule carries no bonding table (see MolecularStructure.create's (name, elms, coords) signature), so interatomic distance is the only connectivity proxy available.

BAYSOL.BAYSOL_Utils.Constants.CUTOFF_DEBYE_LENGTHS — Constant

Charge sites beyond this many Debye lengths from a bead are dropped in the screened-electrostatic aggregation (exp(-5) ≈ 0.007, already negligible next to the screened 1/r prefactor).

source
BAYSOL.BAYSOL_Utils.Constants.DEBYE_TEMPERATURE_K — Constant

Solution temperature, K, for the Debye screening-length calculation (debye_length's default T). Distinct from DEFAULT_TEMPERATURE_C (25°C ≈ 298.15 K), which is _ρₑ/ρₑ_prior's own default temperature for the bulk-electron-density calculation — the two aren't currently reconciled to the same value; each keeps its own pre-existing default here rather than silently changing either one.

BAYSOL.BAYSOL_Utils.Constants.PHOSPHATE_NET_CHARGE — Constant

Net Manning-condensed charge of a single B-DNA phosphate group, in units of the elementary charge. Laage/Elsaesser/Hynes 2017 section 5.1: the bare -1 e phosphate charge is reduced by counterion condensation to -0.24 e for B-DNA geometry (d_charge = 0.17 nm) with monovalent counterions at T = 300 K, ε = 80 (Γ = λ_B/d_charge = 4.22, η = 1 - 1/Γ = 0.76 bound fraction, net charge 1/(Γ) ... = -0.24).

BAYSOL.BAYSOL_Utils.Cache.KeyedCache — Type
KeyedCache{K,V}()

A thread-safe keyed memoization cache: a Dict{K,V} guarded by one ReentrantLock. K/V stay concrete type parameters (never Any) so Base.get! specializes like a bare Dict lookup would.

source
BAYSOL.BAYSOL_Utils.Cache.Lazy — Type

A cache of a value of type T. The thunk runs on the first force.

source

source
Base.get! — Method
Base.get!(f::Union{Function,Type}, c::KeyedCache{K,V}, key::K) -> V

Return the cached value for key, computing it via the zero-arg thunk f and storing it on the first miss. The lookup, compute-on-miss, and store are all done under c's lock, so concurrent callers racing on the same missing key never double-store or observe a torn Dict.

Arguments

  • f: zero-arg thunk, run only on a cache miss for key.
  • c: the cache to look up/store into.
  • key: the lookup key.
