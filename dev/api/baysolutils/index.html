BAYSOL_Utils

Shared infrastructure used across the rest of the package: physical/numeric constants, the lazy-value cache primitives, and per-stage run timing.

BAYSOL.BAYSOL_Utils.Constants.BACKBONE_ELECTRONS — Constant

Peptide backbone unit (-CH2CONH-, neutral, C2H3NO) electron count: 2×C(6) + 3×H(1) + N(7) + O(8) = 30 e. Added once per residue on the same basis as BACKBONE_PMV; Protein.json's electron_count field is a side-chain-only increment relative to glycine.

source
BAYSOL.BAYSOL_Utils.Constants.BACKBONE_PMV — Constant

Peptide-bond backbone unit (-CH2CONH-, "glycyl") partial molar volume at 25 °C, (value, uncertainty) in cm³·mol⁻¹, added once per residue by the protein PMV backend. Protein.json's per-residue entries (A, V, L, ... and G's zero) are side-chain-only increments relative to glycine (Lee et al. 2008's own convention), not absolute residue volumes. Source: Protein.tsv CH2CONH row, 10.1039/9781782627043-00542.

source
BAYSOL.BAYSOL_Utils.Constants.BESSEL_CUTOFF — Constant

Threshold below which a spherical Bessel value jₗ(q·r) is treated as zero in Scattering.compute_B_lm: degree-l columns with q·rmax < xcut(l), where xˡ/(2l+1)!! = BESSELCUTOFF (an upper bound on |jₗ|), are skipped. Each skipped term is below BESSELCUTOFF·|f|, far under any tolerance on G.

source
BAYSOL.BAYSOL_Utils.Constants.B_LM_CHUNK — Constant

Atoms/dummies per pass in Scattering.compute_B_lm.

source
BAYSOL.BAYSOL_Utils.Constants.B_LM_TILE — Constant

Atoms per inner tile of Scattering.compute_B_lm: the inner dimension of each per-degree BLAS product. Large enough that dgemm runs near peak (measured at 256), small enough to bound the W buffer together with B_LM_W_BYTES. Results are tile-invariant up to rounding.

source
BAYSOL.BAYSOL_Utils.Constants.B_LM_W_BYTES — Constant

Memory budget, in bytes, for the per-tile W buffer (all degrees ≤ lMax, every amplitude column, a q-tile) in Scattering.compute_B_lm; the q-tile length is chosen to fit it.

cm³ per litre.

Default absolute tolerance for floating-point equality checks (abs(a - b) < DEFAULTATOL, or isapprox(a, b; atol = DEFAULTATOL)): a few orders of magnitude above Float64 roundoff.

BAYSOL.BAYSOL_Utils.Constants.DEFAULT_QUANTILES — Constant

"lo-hi" empirical quantile range (integer percentages, 0 ≤ lo < hi ≤ 100) used to build "quantiles"/"bounds" entries. The default "16-84" is a ±1σ-equivalent interval for a Normal. The special case "0-0" means no filtering.

source
BAYSOL.BAYSOL_Utils.Constants.DEFAULT_TARGET_ACCEPT — Constant

Default NUTS target acceptance rate, as a percentage in (0, 100), for run_model / Fitting.run_fitting: Stan's usual default of 80 %.

source
BAYSOL.BAYSOL_Utils.Constants.DEFAULT_TEMPERATURE_C — Constant

Default solution temperature, °C, for ρₑ/[`Fitting.ρₑprior](@ref BAYSOL.Fitting.ρₑ_prior)'s bulk-electron -density calculation. Pass the sample's real temperature instead whenever it is known: water's density is evaluated at it exactly, and the solutes' 25 °C partial molar volumes get a widened uncertainty (see [PMVFRACTIONALEXPANSIBILITY`](@ref)).

source
BAYSOL.BAYSOL_Utils.Constants.DRO12_CONCENTRATION — Constant

Default concentration κ = α + β − 2 of the δρ₁/δρ₂ Beta priors (Fitting.δρ_prior). κ = 14 gives Beta(83/6, 13/6) on DRO_BOUNDS, with its mode at δρ = 1 and SD(δρ) ≈ 1.00. That is the same spread as the Normal(1, 1) δρ₂ prior it replaces.

source
BAYSOL.BAYSOL_Utils.Constants.DRO12_MODE — Constant

CRYSOL3's default convex/concave shell contrast δρ₁ = δρ₂, in units of DRO_UNIT: "The default parameters of the contrasts for the three types of water beads are 1, 1, 0". The mode of the δρ₁/δρ₂ priors (Fitting.δρ_prior); must lie inside DRO_BOUNDS.

source
BAYSOL.BAYSOL_Utils.Constants.DRO3_CONCENTRATION — Constant

Default concentration κ = α + β − 2 of the cavity-contrast (δρ₃) Beta prior (Fitting.δρ_prior), stretched onto [−ρ̄ₑ/DRO_UNIT, (φ_max − 1)·ρ̄ₑ/DRO_UNIT]. κ = 1.25 gives Beta(2, 1.25) on u = (δρ₃ − X)/W, with its mode at δρ₃ = 0 (bulk-density cavity water).

source
BAYSOL.BAYSOL_Utils.Constants.DRO_BOUNDS — Constant

CRYSOL3's fitting limits (lo, hi) on the convex/concave shell contrasts δρ₁, δρ₂, in units of DRO_UNIT: "The limits during the fitting are -10 to 2". They are the support of the δρ₁/δρ₂ priors (Fitting.δρ_prior) and of the scaled-logit maps Fitting.Θ/Fitting.Ξ put on them.

source
BAYSOL.BAYSOL_Utils.Constants.DRO_UNIT — Constant

Shell-contrast unit in e·Å⁻³ (CRYSOL's –dro); drok = DROUNIT * δρ_k.

source
BAYSOL.BAYSOL_Utils.Constants.EXCL_VOL_CORR_BOUNDS — Constant

Hard bounds (cmin, cmax) on CRYSOL's excluded-volume correction c1 (Fitting.profiled_corrs), CRYSOL's r₀/r_m. c1 is profiled, not sampled, so these bounds – not a prior – are what stops it from absorbing model misspecification that belongs on the physically meaningful parameters (dns/δρ1-3) instead.

source
BAYSOL.BAYSOL_Utils.Constants.EXCL_VOL_CORR_EPS — Constant

Padding/grid-resolution unit for Fitting.profiled_corrs's c1 search: the search actually runs on (cmin - EXCL_VOL_CORR_EPS, cmax + EXCL_VOL_CORR_EPS) so that landing exactly on cmin/cmax can be distinguished from genuinely wanting to go further (real "saturation"), and the same value is the coarse pre-scan grid's step size.

source
BAYSOL.BAYSOL_Utils.Constants.F2_LOG_FLOOR — Constant

Floor applied to Chantler f2 table values before the log-log interpolation in FormFactor.f1f2: f2 is positive and spans decades, and the floor keeps the log finite where the table stores an exact zero.

source
BAYSOL.BAYSOL_Utils.Constants.GAUTSCHI_MARGIN — Constant

Start order of the continued-fraction sweep in Scattering.SphFuncs.sphBessRatios!: N = max(lMax, ⌈x⌉) + GAUTSCHIMARGIN[1] + ⌈GAUTSCHIMARGIN[2]·x^(1/3)⌉. Deep enough that every ratio is converged to the Float64 rounding floor (the floor is reached at (12, 5) against a 512-bit reference; (16, 6) leaves a safety step).

source
BAYSOL.BAYSOL_Utils.Constants.NS_PER_S — Constant

Nanoseconds per second: converts time_ns() and Base's *_time_ns() counters to seconds.

source
BAYSOL.BAYSOL_Utils.Constants.N_VOL_SHELL — Constant

Default number of points to generate to sample excluded volume. 10.1016/j.bpj.2023.10.034 uses a 16³ voxel grid for each atom; a sphere occupies π/6 of the cube. This works out to roughly (π/6 * 16³) ≈ 2145 points being occupied.

BAYSOL.BAYSOL_Utils.Constants.PMV_FRACTIONAL_EXPANSIBILITY — Constant

Fractional partial-molar-volume expansibility, K⁻¹: an upper bound on (∂ϕ°/∂T)/ϕ° used to widen a solute's 25 °C ϕ° uncertainty when the sample is at another temperature, σT = PMVFRACTIONAL_EXPANSIBILITY · ϕ° · |t - 25|.

Derived from the multi-temperature series bundled with the tables (15-35 °C: sugars, ureas and glycolurils in sources/extractedpmvcandidates.tsv; 18-40 °C: Chalikian et al. 2001's nucleobases/nucleosides, 10.1016/S0301-4622(01)00200-9, the other-T rows of nonbiological.tsv): across those 42 solutes the fractional expansibility spans 0.44-2.96 × 10⁻³ K⁻¹ (median 0.82 × 10⁻³), so 3.0 × 10⁻³ covers every one of them. No electrolyte has multi-temperature data in the tables, so this bound is unverified for salts.

source
BAYSOL.BAYSOL_Utils.Constants.PMV_REFERENCE_TEMPERATURE_C — Constant

Temperature, °C, at which the bundled partial-molar-volume tables are tabulated (see PartialMolarVolumes/README.md: 298.15 K unless a source says otherwise).

BAYSOL.BAYSOL_Utils.Constants.PROBE_RADIUS — Constant

Solvent probe radius in Å (water), forwarded to SASA.shell_points.

BAYSOL.BAYSOL_Utils.Constants.SASA_AREA_TOL — Constant

Default area tolerance (Å²) in SASA.sasa: an atom with no witness in the SASA_N_OCC pass may still expose up to 3/nocc of its sphere (rule of three); if that worst-case area is below this, the full [`SASAN_EXP`](@ref) pass is skipped and the atom is treated as buried.

source
BAYSOL.BAYSOL_Utils.Constants.SASA_N_EXP — Constant

Default exposed-fraction point count per atom in SASA.sasa. Measured relative error against the analytic two-sphere cap: 1.3 % at 64 points, 0.36 % at 1024, 0.065 % at 4096, 0.02 % at 16384; costs ~0.09 ms/atom.

source
BAYSOL.BAYSOL_Utils.Constants.SASA_N_OCC — Constant

Default witness-pass point count per atom in SASA.sasa: the smallest round count measured to lose no area on a dense lattice. Catches any atom exposed by more than ~1/512 of its sphere (about 0.2 Å²).

source
BAYSOL.BAYSOL_Utils.Constants.SHELL_AREA_PER_POINT — Constant

Å² of accessible surface each shell point stands for; sets the cloud's spacing at ≈ √SHELLAREAPER_POINT ≈ 2 Å.

Calibrated against CRYSOL: its default –fb 17 puts F(17) = 1597 points on a typical globular protein (~6500 Å²), i.e. ~4 Å² each. Budgeting by area rather than by a fixed count keeps that spacing at every size, and since surface area grows as N^(2/3), the point count is sub-linear in atom count rather than flat. CRYSOL instead caps –fb at F(18) = 2584 for any structure, which under-resolves large complexes; pass n_target explicitly to reproduce that.

source
BAYSOL.BAYSOL_Utils.Constants.SHELL_MIN_POINTS — Constant

Floor on the derived point budget: F(10), the smallest Fibonacci grid CRYSOL's –fb accepts.

source
BAYSOL.BAYSOL_Utils.Constants.SHELL_N_TARGET — Constant

Default shell-dummy budget (hydration's ntarget). nothing lets [`SASA.shellpoints`](@ref BAYSOL.SASA.shellpoints) size the cloud from the accessible area (≈ area / SHELLAREAPERPOINT, floored at SHELLMINPOINTS); an Int pins it.

source
BAYSOL.BAYSOL_Utils.Constants.SHELL_THICKNESS — Constant

Hydration-shell thickness in Å: how far the perturbed-density water layer extends beyond the solvent-accessible surface. 3.0 is CRYSOL's border-layer default.

BAYSOL.BAYSOL_Utils.Constants.φ_max — Constant

Upper bound on the cavity occupancy φ = ρcavity/ρ₀. Water in a cavity can be at most modestly denser than bulk: the densest well-attested hydration water is Merzel & Smith's first layer at 1.15·ρ₀, so φmax = 1.25 leaves margin above it while excluding unphysical over-dense "water" (e.g. the δρ3 = 4, φ ≈ 1.36, seen when δρ3 was unconstrained).

Cache

BAYSOL.BAYSOL_Utils.Cache — Module

Thread safe caching primitives.

source
BAYSOL.BAYSOL_Utils.Cache.KeyedCache — Type
KeyedCache{K,V}()

A thread-safe keyed memoization cache: a Dict{K,V} guarded by one ReentrantLock. K/V stay concrete type parameters (never Any) so Base.get! specializes like a bare Dict lookup would.

source
BAYSOL.BAYSOL_Utils.Cache.Lazy — Type

A cache of a value of type T, built unforced as Lazy{T}(f) from a zero-arg thunk f; f runs on the first force.

source
BAYSOL.BAYSOL_Utils.Cache.force — Method
force(c::BAYSOL.BAYSOL_Utils.Cache.Lazy{T}) -> Any

Run c's thunk once, under its lock, then return the stored value on every call.

Arguments

- `c`: the cache to force.
source
Base.get! — Method
get!(
    f::Union{Function, Type},
    c::BAYSOL.BAYSOL_Utils.Cache.KeyedCache{K, V},
    key
) -> Any

Return the cached value for key, computing it via the zero-arg thunk f and storing it on the first miss. The lookup, compute-on-miss, and store are all done under c's lock, so concurrent callers racing on the same missing key never double-store or observe a torn Dict.

Arguments

  • f: zero-arg thunk, run only on a cache miss for key.
  • c: the cache to look up/store into.
  • key: the lookup key.

haskey(

Whether key has already been memoized in c, taken under c's lock.

Timing

BAYSOL.BAYSOL_Utils.Timing — Module

Wall-clock, JIT-compile and GC time per named stage of a run, for the report's === Timing === section. A StageLog is created when a run starts and is handed down to whatever should be timed; everything is a no-op when the log is nothing.

source
BAYSOL.BAYSOL_Utils.Timing.Stage — Type

One timed stage. group is :static, :sampling or :report; depth 1 is a direct child of its group, 2 a child of the preceding depth-1 stage, and so on. compile and gc are the seconds of seconds spent compiling and in GC. note is free text printed next to the name (e.g. [cache hit]).

source
BAYSOL.BAYSOL_Utils.Timing.StageLog — Type

Stages in execution order (a parent precedes its children), the start time of the run (t0, time_ns(); compile0, the compile counter then), and free-form run facts (info, e.g. lMax, n_samples).

source
BAYSOL.BAYSOL_Utils.Timing.fmt_count — Method
fmt_count(
    n::Integer
) -> Union{Base.AnnotatedString{String}, String}

A count for the timing report: plain below 1000, else thousands with up to two decimals and no trailing zeros (2000 → 2k, 14210 → 14.21k, 1500 → 1.5k).
