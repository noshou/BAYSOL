Pipeline: results and figures

results and the figure options PlotStyle and Reference (src/Pipeline/Results.jl): the terminal plots, the pgfplots .tex figures and the optional LaTeX compile; and compare_results (src/Pipeline/Compare.jl), the models of a run and the reference curves on one figure, with the reader of a project's reference curves. The end-of-run summary, the run log and the workbook sheets are on Pipeline: run log and tables; the entry points are on Pipeline: entry points and the defaults of the figure look on Pipeline: settings.

BAYSOL.Pipeline.ColorSpec — Type

A colour: anything Colors.parse reads (:crimson, "crimson", "#dc143c"), or a (colour, opacity) tuple such as (:darkorange, 0.15).

The PGFPlotsX engine of each LaTeX compiler a latex_compiler path may name (by its file name without the extension).

BAYSOL.Pipeline.PlotStyle — Type
PlotStyle(; color_map, color_posterior, …)

The look of the figures of results. Every field is a keyword argument, and each defaults to the PLOT_-prefixed constant of Pipeline of the same name (PlotStyle().color_map is PLOT_COLOUR_MAP).

Fields

  • color_map, color_posterior, color_data, color_errorbar, color_band, color_band_resid, color_hist, color_reference, color_axis, color_tick: ColorSpecs.
  • lw_map, lw_reference, lw_quantile, lw_quantile_resid, lw_zero_line, lw_errorbar, lw_compare: line widths (pt).
  • colors_compare, markers_compare: for compare_results, the colours of the fitted curves of the models and the markers of the reference curves, each a tuple of Symbols (a colour name or Symbol("#rrggbb"); a marker of PLOT_MARKER_NAMES), assigned in order and cycled when there are more curves than entries.
  • markersize, whiskerwidth: the data markers' radius and the error bars' whisker (pt).
  • hist_bins: bins of each posterior histogram.
  • size_cm: (width, height) of every figure (cm), the same for all of them.
  • ylim_log, ylim_lin_pad_frac: the y-ranges of the I(q) and the residuals plots.
  • preview_size: (width, height) of a terminal plot (characters, rows).
  • border_pt: the padding the PDF page keeps round a figure (pt).
  • lw_axis: the line width of the axis box (pt); its colour is color_axis.
  • lw_tick, lw_minor_tick, tick_length_cm, minor_ticks, tick_label_pad_pt: the axis ticks, in color_tick (line widths of the major and the minor ticks in pt, major length in cm, the minor ticks between two major ones of a linear axis) and the gap between the y axis and its tick labels (pt).
  • xtick_angle: the angle the x tick labels are turned by (degrees; 0 leaves them level).
  • xtick_label_pad_pt: the gap between the end of an x tick and its label (pt).
  • tick_stub_pt, tick_elbow_pt: each x tick leaves the axis straight for tick_stub_pt and then bends for tick_elbow_pt towards its slanted label (pt).
  • font: the font of the LaTeX output: the name of any font LuaLaTeX can find (the text font; the math font stays Latin Modern Math), a (text font, math font) pair of fontspec names (the default is PLOT_FONT, that is PLOT_TEXT_FONT, TeX Gyre PagellaX, with PLOT_MATH_FONT, TeX Gyre Pagella Math), or nothing for the LaTeX default. font_available says whether a name is usable. A font needs lualatex or xelatex.

BAYSOL.Pipeline.Reference — Type
Reference(name, q, I; q_max = Inf)

A curve to compare the fit with (the depositor's CRYSOL, FoXS, … fit), drawn with the measured points and the MAP curve on a figure of its own. name labels it in the legend and in the file name. Points with a non-finite or non-positive q or I (not drawable on log axes) or with q > q_max are dropped.

Returns

  • The Reference.

Exceptions

  • ArgumentError if q and I differ in length or no point is left.

BAYSOL.Pipeline._curve_data — Method

The I(q) figure's data: the measured points with positive intensity (the log axes cannot show the others; the fit itself used every point), their error bars' ends (err_lo, err_hi; a plain additive I ± σ interval is not symmetric on a log axis, so σ is propagated into log space by the delta method and the interval is log-symmetric and always positive), the quantile and bounds curves floored at half the smallest intensity (a model can graze 0 at the noise floor, which a log axis cannot show), the MAP curve (non-positive values as NaN), and the y-range centred on the data.

BAYSOL.Pipeline._engine_kwargs — Function

The PGFPlotsX.save keywords that pick the LaTeX engine. With a compiler (the path of lualatex, xelatex or pdflatex) that one, and nothing else (a path that is set is never replaced by another compiler); without one, as for a font: with a font, lualatex or else xelatex (the fonts are fontspec fonts, which pdflatex cannot load); without a font, nothing, and PGFPlotsX uses the first engine it finds.

Exceptions

  • ErrorException if compiler is not a file or not named for one of the three engines, or a font is given and the compiler is pdflatex; if there is a font and no compiler and neither lualatex nor xelatex is installed, or LuaLaTeX cannot find the font.

BAYSOL.Pipeline._text_of_size — Method

The text of a terminal plot that is width columns wide as a whole (labels, ticks and legend included) and has a plot area of height rows. render(w, h, bins) draws the plot with the area w wide, h rows tall and, for a histogram, bins bins. The labels and the legend add a width of their own, so the area's width is corrected until the widest line is width (a title or a legend wider than that cannot be cut: then the narrowest drawing found is the result, which a caller can read off the text). A histogram's bin count is only a suggestion (the edges are rounded to nice numbers, so a bimodal sample gets more bins), so it is lowered until the plot is at most height plus the rows round the area. The colour codes are taken out.

Returns

  • The plain text of the plot, lines joined by a newline.

Exceptions

  • None.

BAYSOL.Pipeline.results — Method

The figures of a fit run by run_model, and the numbers behind them. Three figures are made, each from the same prepared data:

  • the fit: the measured points with their error bars, the posterior bounds band and quantile curves, and the MAP curve, on log axes (<name>);
  • the residuals: data minus MAP with the band and quantile curves minus MAP (<name>_residuals);
  • the histograms of the non-divergent draws of ρₑ, δρ₁, δρ₂, δρ₃, scale, background and c1, each its own figure with the MAP value marked (<name>_hist_rho_e, <name>_hist_delta_rho_1, …, <name>_hist_c1);

and one comparison figure per entry of references (data, reference curve, MAP curve; <name>_comparison, or <name>_comparison_<reference name> when there are several). The models of one run, with all the references, on ONE figure are compare_results.

The files are laid out under dir: the .tex figures (and what is compiled from them) in dir/plots/, and the numbers as one workbook dir/<name>.xlsx; the run's log (timings and what is worth tracking), which write_log writes when run_log = true, is the section of name in dir/<folder name>.LOG. name is the first part of every file name, so several runs can share a folder. Three kinds of output come out of each figure:

  • a terminal preview printed to io (preview = true), made with UnicodePlots, which needs nothing installed;
  • a pgfplots .tex file (tex = true), a standalone document that needs no LaTeX to write. The default does not run LaTeX (it takes about a second per figure); with compile = true each document is also compiled to the formats (:pdf, :png, :svg; this needs a LaTeX engine, and poppler's pdftocairo/pdftoppm for :png/:svg). A failed run is a warning and the .tex stays;
  • the numbers, always written, as one workbook. Sheet and column names are plain ASCII, and every value is a number (a statistic that could not be computed is an empty cell) except the labels in the first column and the text of form_factor_log. The sheets:
    • run: section | name | value | unit | meaning, the run's settings and statistics: model sizes, sampler settings, the Shannon binning, the sampler's diagnostics and the chains' convergence;
    • map: parameter | value, the MAP value of each parameter;
    • quantiles_<interval>: parameter | quantile_lo | quantile_hi | bound_lo | bound_hi, the posterior quantile pair of each parameter and the extreme draws inside it;
    • stdev_from_prior: parameter | z_map | z_quantile_lo | z_quantile_hi, how far the MAP value and the quantile pair of the four prior-carrying parameters lie from the prior mean, in prior standard deviations (θ-space);
    • modes and optima: only when the posterior has more than one mode or optimum;
    • form_factor_log: only when form_factor_log is given or the seed has one;
    • data (q | I | sigma, the fitted curve), model (q | I_map | quantile_lo | quantile_hi | bound_lo | bound_hi), residuals (q | I | sigma | I_map | residual), one hist_<parameter> (bin_lo | bin_hi | count) for each histogram, draws (one tidy table, a row for each draw, header frozen and units in the header text: chain, draw within the chain, the four sampled parameters, scale, bkgrnd_corr, excl_vol_corr, chi2_fit_grid, and the sampler's flags log_density, divergent, tree_depth, n_steps, step_size and acceptance_rate, each only if the statistics carry it) and one ref_<name> (q | I) for each reference curve.
    The README of src/Pipeline/ explains every row of run.

The time of each figure (its data, preview, .tex and LaTeX run), of the summary tables and of writing the workbook is recorded in the run's timing log as stages of the plot group, so the log's timings list them; with run_log it calls write_log last.

Arguments

  • result: what run_model returned.
  • data: the curve the fit saw, (q, I, σ), which is seed.shannon.q, .I, .σ; or the seed itself.
  • dir, name: the output folder (created if missing, with its plots/ subfolder as it is needed) and the first part of the file names.
  • references: References, a vector or a single one.
  • style: a PlotStyle.
  • font: the font of the LaTeX figures, style.font unless given: the name of any font LuaLaTeX can find (the text font), a (text font, math font) pair, or nothing for the LaTeX default (which pdflatex also compiles). The default is TeX Gyre PagellaX with TeX Gyre Pagella Math, and font_available checks a name. A font needs lualatex or xelatex to compile; the terminal plots and the data do not depend on it.
  • preview, io: whether to print the terminal plots, and where.
  • tex, compile, formats: as above.
  • run_log: also write the run's section of the folder's run log (write_log), false by default; the fitting tests set it. The log is then in the files returned.
  • ref_chi2: the reference χ², the depositor's with its method ("CRYSOL 1.37"), which the log prints in the run's section as the ref_chi2 row (only with run_log).
  • form_factor_log, n_atoms: the seed's seed.fw.form_factor_log and seed.fw.n_atoms for the form_factor_log and run sheets; given by themselves when data is a Seed.
  • table_sigfigs::Integer = TABLE_SIGFIGS: significant figures of every number of the workbook (17 writes every bit of a Float64; at least 1).
  • plot_tui_sizes = PLOT_TUI_SIZES, tui_dir = nothing: with a tui_dir the terminal plots are also drawn at each of the sizes plot_tui_sizes (the setting PLOT_TUI_SIZES: (width, height) pairs, the width of the whole plot in columns and the height of its area in rows) and written into that folder as plots_<width>x<height>.txt, in the layout of io (so a viewer can pick the largest that fits its window); run_project does it in :tui mode. Without tui_dir the sizes are checked and nothing is written.
  • plot_dir::AbstractString = FIGURES_DIR: with a path (not ""), the .tex figures are also copied into that folder (made if missing; a file of the same name is replaced). run_project gives each model its own <plot folder>/<project>/<run>/<model>.
  • latex_compiler::AbstractString = FIGURES_COMPILER: the path of the compiler compile runs, lualatex, xelatex or pdflatex, named by its file; "" looks for lualatex, then xelatex, on the PATH. A compiler that is set is the only one tried.

Returns

  • The paths of the files written (the copies in plot_dir are not listed).

Exceptions

  • ArgumentError if the style holds a value that cannot be drawn (a non-positive size or bin count, a negative width), formats holds anything but :pdf, :png and :svg, or data has no positive intensity, its three vectors differ in length, or font is not nothing, a font name or a pair of names.
  • InvalidSettingsError if table_sigfigs is not a whole number of at least 1 (the check of load_settings for TABLE_SIGFIGS), plot_tui_sizes is not a valid PLOT_TUI_SIZES, or plot_dir or latex_compiler is not a path (text without control characters).
  • SystemError if the plot folder cannot be made or written.

BAYSOL.Pipeline._compare_data — Method

The data of the comparison figure, prepared once for all three outputs. fits are the results of run_model (each with a MAP curve), names their names, data the measured curve (q, I, σ) and refs the References.

The measured points are as _curve_data makes them (positive intensities, log-symmetric error bars, the y-range centred on them). Each model has its name, its colour (the k-th of style.colors_compare, cycling), the TeX name of that colour, its MAP curve on its own q grid (map, non-positive values NaN for the log axes; map_raw as it is, for the workbook), its reduced χ² and, with a single model only, its bounds band (several bands over each other are not readable). Each reference has its marker (the k-th of style.markers_compare, cycling).

BAYSOL.Pipeline._compare_sheets — Method

The comparison plot in the terminal: the data, each reference (a thin line of its marker) and each model's MAP curve in its colour, as log₁₀ q against log₁₀ I(q). The bounds band is in the .tex only. References share one colour, so the terminal tells them apart by their marker.

BAYSOL.Pipeline._read_reference — Method

The reference curve in the text file path: two or three numeric columns (q, I and an optional σ, which is read and not used), separated by white space, tabs, commas or semicolons. Blank lines and everything from a # to the end of a line are skipped, and so are text lines before the first row of numbers (a header). The curve is named by the file's stem. q_scale multiplies q (0.1 turns nm⁻¹ into Å⁻¹).

Returns

  • The Reference; points that cannot be drawn on log axes are dropped as it does.

Exceptions

  • ArgumentError naming the file (and the line) for a line that is not text of two or three numbers once the data has begun, a file without a numeric row, or one with no usable point.
  • SystemError if the file cannot be read.

BAYSOL.Pipeline._read_references — Method

The reference curves of the folder folder (a project's reference-fit/): every file with one of the REFERENCE_EXTENSIONS, in name order, read by _read_reference. A stem that is taken (a.tsv and a.dat) gets -2, -3, … so that every curve has its own name. A file that cannot be read is skipped and described in the returned problems; it never stops the others.

Returns

  • (references, problems): the curves, and one line of text for each file that was skipped, naming the file. A missing folder holds no curves and no problems.

Exceptions

  • None.

BAYSOL.Pipeline.compare_results — Method
compare_results(fits, data; names, references, dir, name, style, font, preview, io,
    tex, compile, formats, table_sigfigs, plot_tui_sizes, tui_dir) -> Vector{String}

The combined comparison of a run, ONE figure for the results of several models of the same measured curve: the measured points with their error bars, the fitted (MAP) curve of every model, in the colours of style.colors_compare (the first model takes the first colour, and so on, cycling), and every Reference (the depositor's fit, CRYSOL, FoXS, … ) as a dashed line in the reference colour carrying the marker of style.markers_compare that its place in references gives it (cycling). With a single model the posterior bounds band of the single-model figure is drawn too; with several the bands would hide each other and are left out. Log axes, as the other I(q) figures. run_project calls it after the last model of a run when the setting PLOT_COMPARE is on, into the run's compare/ folder.

Three outputs come out of it, as from results: the figure in the terminal (printed to io, preview = true), the pgfplots <name>_compare.tex in dir/plots/ (tex = true; LaTeX is run only with compile = true, to the formats, and a failed run is a warning), and the workbook dir/<name>_compare.xlsx of the same curves, always written, with two sheets: compare (q, the measured I and sigma, then a column for the fit of each model and one for each reference, each interpolated onto the measured q: empty where a curve does not reach, exact where it is on that grid) and legend (the colour, marker and line style of each column, the models' MAP χ² and a note), so the figure can be drawn again in any other program.

Arguments

  • fits: the results of run_model, one per model, of the SAME measured curve. A result without a MAP curve (every draw diverged) has nothing to draw: it is skipped with a warning.
  • data: the measured curve (q, I, σ) (q in Å⁻¹) that every fit was made from; the figure shows these points, not each model's own binned curve.
  • names: the model names, model1, model2, … by default; they label the legend and the columns, and must differ.
  • references: References, a vector or a single one.
  • dir, name: the output folder (created if missing) and the first part of the file names (<name>_compare).
  • style, font: a PlotStyle and the font, as for results.
  • preview, io, tex, compile, formats: as for results.
  • table_sigfigs: significant figures of every number of the workbook (17 writes every bit of a Float64; at least 1).
  • plot_tui_sizes, tui_dir: as for results: with a tui_dir the terminal plot is also drawn at each size of plot_tui_sizes and written there as plots_<width>x<height>.txt.

Returns

  • The paths of the files written: the .tex, what was compiled from it, the workbook and the terminal plots of tui_dir.

Exceptions

  • ArgumentError if fits is empty or none has a MAP curve, names has another length than fits or repeats a name, data has no positive intensity or its three vectors differ in length, the style holds a value that cannot be drawn, formats holds anything but :pdf, :png and :svg, or font is not nothing, a font name or a pair of names.
  • InvalidSettingsError if table_sigfigs is not a whole number of at least 1 or plot_tui_sizes is not a valid PLOT_TUI_SIZES.
