PhysicalConstants

Physical constants and units shared across the package, defined once (src/PhysicalConstants/).

BAYSOL.PhysicalConstants — Module

Physical constants and units shared across the package, defined once so they cannot drift between modules. Loaded first; every other module imports what it needs from here (using ..PhysicalConstants: AVOGADRO).

source
BAYSOL.PhysicalConstants.ANGSTROM3_PER_LITER — Constant

Å³ per litre: 1 L = 10⁻³ m³ = 10²⁷ Å³.

source
BAYSOL.PhysicalConstants.ANGSTROM_PER_METER — Constant

Å per metre.

source
BAYSOL.PhysicalConstants.AVOGADRO — Constant

Avogadro constant, mol⁻¹ (CODATA, exact since the 2019 SI redefinition).

source
BAYSOL.PhysicalConstants.BACKBONE_ELECTRONS — Constant

Peptide backbone unit (-CH2CONH-, neutral, C2H3NO) electron count: 2×C(6) + 3×H(1) + N(7) + O(8) = 30 e. Added once per residue on the same basis as BACKBONE_PMV; Protein.json's electron_count field is a side-chain-only increment relative to glycine.

source
BAYSOL.PhysicalConstants.CM3_PER_LITER — Constant

cm³ per litre.

source
BAYSOL.PhysicalConstants.DRO_UNIT — Constant

Shell-contrast unit in e·Å⁻³ (CRYSOL's –dro); dro_k = DRO_UNIT * δρ_k.

source
BAYSOL.PhysicalConstants.ELEMENTARY_CHARGE — Constant

Elementary charge e, C (exact since the 2019 SI redefinition).

source
BAYSOL.PhysicalConstants.HC_EV_ANGSTROM — Constant

h·c in eV·Å, from the exact SI values of h, c and e: ≈ 12398.41984. Photon energy from wavelength: E (eV) = HC_EV_ANGSTROM / λ (Å).

source
BAYSOL.PhysicalConstants.KELL_DENSITY_DEN — Constant

Denominator coefficient b of the Kell equation (see KELL_DENSITY_NUM), °C⁻¹.

source
BAYSOL.PhysicalConstants.KELL_DENSITY_NUM — Constant

Numerator coefficients (a₀, …, a₅) of the Kell equation (1975) for the mass density of pure water at 1 atm, kg·m⁻³, valid 0–150 °C: ρ(t) = (a₀ + a₁t + a₂t² + a₃t³ + a₄t⁴ + a₅t⁵) / (1 + b·t), t in °C, with b = KELL_DENSITY_DEN.

source
BAYSOL.PhysicalConstants.MS_PER_S — Constant

Milliseconds per second.

source
BAYSOL.PhysicalConstants.NM_INV_PER_ANGSTROM_INV — Constant

nm⁻¹ per Å⁻¹ (1 Å⁻¹ = 10 nm⁻¹). A curve deposited in nm⁻¹ is converted with q ./ NM_INV_PER_ANGSTROM_INV. (An integer, so the division is bit-identical to q ./ 10.)

source
BAYSOL.PhysicalConstants.NS_PER_S — Constant

Nanoseconds per second: converts time_ns() and Base's *_time_ns() counters to seconds.

source
BAYSOL.PhysicalConstants.PLANCK_CONSTANT — Constant

Planck constant h, J·s (exact since the 2019 SI redefinition).

source
BAYSOL.PhysicalConstants.PM_PER_ANGSTROM — Constant

pm per Å (the bundled ionic-radius table is in pm).

source
BAYSOL.PhysicalConstants.SPEED_OF_LIGHT — Constant

Speed of light in vacuum c, m·s⁻¹ (exact).

source
BAYSOL.PhysicalConstants.STANDARD_TEMPERATURE_C — Constant

Standard reference temperature, °C: 298.15 K, the temperature standard-state data (e.g. the bundled partial-molar-volume tables) are given at. Backs both PartialMolarVolumes.PMV_REFERENCE_TEMPERATURE_C and Fitting.DEFAULT_TEMPERATURE_C, so the tables' temperature and the default sample temperature cannot drift apart.

source
BAYSOL.PhysicalConstants.WATER_DENSITY_UNCERTAINTY — Constant

Absolute uncertainty on the Kell water density, kg·m⁻³ (≈ 20 ppm of ρ, nearly constant 0-150 °C).

source
BAYSOL.PhysicalConstants.WATER_ELECTRONS — Constant

Electrons per H₂O molecule (2 from H, 8 from O).

source
BAYSOL.PhysicalConstants.WATER_MOLAR_MASS — Constant

Molar mass of H₂O, g·mol⁻¹ (IAPWS-95 value).
