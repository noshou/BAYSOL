Utils

The small scientific helpers the others build on (src/Utils/): physical constants and units, low-discrepancy point sets, and the Shannon-channel data reduction.

Utils

BAYSOL.Utils — Module

Small scientific helpers the rest of the package builds on: physical constants, low-discrepancy point sets and Shannon binning. Each is re-bound at the package root (BAYSOL.PhysicalConstants, …). The process machinery (caching, timing, GC pausing) is in Runtime.

PlasticSequence

BAYSOL.Utils.PlasticSequence — Module

Even point sets drawn from the plastic (R_d) family of additive low-discrepancy sequences (Roberts, M. (2018). The Unreasonable Effectiveness of Quasirandom Sequences.). dim selects the output space:

  • dim = 2: the raw 2-D R₂ generator, unlifted, in the plane.
  • dim = 3: the same 2-D R₂ generator lifted onto a sphere, either its

surface (shape = :surface, the default: a 2-D manifold, since a sphere's surface only takes 2 coordinates to parametrize) or its volume (shape = :volume: a genuinely 3-D region, built from the 3-D R₃ generator instead, since filling a ball needs a 3rd, radial, coordinate).

source
BAYSOL.Utils.PlasticSequence.PLASTIC_RATIO_2 — Constant

2-D plastic ratio, the real root of x³ = x + 1

source
BAYSOL.Utils.PlasticSequence.PLASTIC_RATIO_2_SQR — Constant

Square of 2-D plastic ratio

source
BAYSOL.Utils.PlasticSequence.PLASTIC_RATIO_3 — Constant

3-D plastic ratio, the real root of x⁴ = x + 1

source
BAYSOL.Utils.PlasticSequence.PLASTIC_RATIO_3_CUBE — Constant

Cube of 3-D plastic ratio

source
BAYSOL.Utils.PlasticSequence.PLASTIC_RATIO_3_SQR — Constant

Square of 3-D plastic ratio

source
BAYSOL.Utils.PlasticSequence.Vec2 — Type

A point in the plane, (x, y).

source
BAYSOL.Utils.PlasticSequence.Vec3 — Type

A unit vector on the sphere, (x, y, z).

BAYSOL.Utils.PlasticSequence._frac — Method

Fractional part of x, i.e. x - floor(x), in [0, 1).

source
BAYSOL.Utils.PlasticSequence._plastic_point_2d — Method

Raw 2-D term i, in [0, 1)².

source
BAYSOL.Utils.PlasticSequence._plastic_point_surface — Method

Unit sphere surface point for 1-based plastic-sequence term i. The 2-D term is read as (azimuth, height) and lifted to the sphere through the equal-area cylindrical projection, so the points are uniform in area rather than clustered at the poles. |p| == 1 for every point.

source
BAYSOL.Utils.PlasticSequence._plastic_point_volume — Method

Unit-sphere volume point for 1-based plastic-sequence term i, built from the 3-D R₃ generator (_plastic_term3). The first two terms are read exactly as in _plastic_point_surface (azimuth φ, cosθ); the 3rd is a radius r = cbrt(w), the inverse-CDF correction for the sphere's r²dr volume element (r = w directly would over-cluster mass at the centre). 0 ≤ |p| < 1 for every point, uniform in volume rather than clustered at the centre.

source
BAYSOL.Utils.PlasticSequence._plastic_term — Method

1-based term i of the 2-D R₂ additive recurrence: (frac(i/ρ), frac(i/ρ²)). Shared by the plane and surface layouts below so a dim = 3 (:surface) cloud and its dim = 2 pre-image agree term for term.

Division by ρ/ρ² (rather than multiplication by reciprocals) keeps the fractional part accurate; it degrades only once i nears the mantissa limit (~1e15), far above any realistic point count.

source
BAYSOL.Utils.PlasticSequence._plastic_term3 — Method

1-based term i of the 3-D R₃ additive recurrence: (frac(i/ρ₃), frac(i/ρ₃²), frac(i/ρ₃³)), ρ₃ = PLASTIC_RATIO_3. A genuinely 3-D generator, distinct from _plastic_term (which only ever has 2 degrees of freedom).

source
BAYSOL.Utils.PlasticSequence.plastic_points — Method

Also has overloaded forms plastic_points(n, ::Val{3}, ::Val{:surface}), plastic_points(n, ::Val{3}, ::Val{:volume}), and a keyword form plastic_points(n; dim=3, shape=:surface); see below.

The first n terms of the plastic low-discrepancy sequence:

- `Val(2)`: the raw 2-D R₂ terms (frac(i/ρ), frac(i/ρ²)), uniform on
[0, 1)².
- `Val(3)`, **or** `Val(3), Val(:surface)` (default via the keyword form):
those same 2-D R₂ terms read as (azimuth, height) and lifted onto the
**surface** of the unit sphere via Lambert's cylindrical equal-area
projection, |p| == 1 always.
- `Val(3)`, `Val(:volume)`: the 3-D R₃ terms lifted to **fill** the unit
sphere. Points are uniform in volume, 0 ≤ |p| < 1.

Every layout is deterministic and prefix-stable: term i never changes as n grows, so plastic_points(k, args...) == plastic_points(n, args...)[1:k] for any k ≤ n and any fixed args.

Arguments

  • n: number of points to generate; n ≥ 0.

Keywords

  • dim: 2 or 3; selects the output space via Val(dim). Default 3.
  • shape: :surface or :volume; only consulted when dim == 3, selects which 3-D layout via Val(shape). Default :surface.

Shannon

BAYSOL.Utils.Shannon — Module

Shannon sampling of a SAXS curve: a particle of diameter D has a scattering curve that carries no information at a q spacing finer than π/D (one Shannon channel), so a curve of thousands of points holds only (q_max - q_min)·D/π independent values. shannon_data bins the measured curve to that resolution and picks the band limit auto_lmax the binned q range needs; cloud_diameter supplies D; model_on_raw and residual_structure check the result against the measured data.

source
BAYSOL.Utils.Shannon.BIN_BIAS_MAX — Constant

Largest worst-case bias of the binning, as a fraction of the smallest binned relative error (bin_bias_ratio), that shannon_data accepts: if the requested rebin gives more, the bins are made finer until the bound is met (or the curve is fitted unbinned). 0.3 keeps the binning's systematic shift of any bin under a third of that bin's smallest error bar.

source
BAYSOL.Utils.Shannon.SHANNON_REBIN — Constant

Default number of bins per Shannon channel (k): the bin width is π/(k·D). Binning at k ≥ 8 preserved the Laplace posterior width and moved the MAP by less than the posterior σ on the fitting tests (see the Shannon section of the Fitting-test README).

source
BAYSOL.Utils.Shannon.ShannonInfo — Type

Everything shannon_data decided about a measured curve, kept in the Inference.Seed so the report and the fitting scripts can reach both the data the fit used and the raw data.

Fields

  • D::Float64: diameter of the scatterer cloud (atoms and hydration-shell beads), Å.
  • lMax::Int: spherical-harmonic band limit the forward model was built with.
  • rebin::Int: bins per Shannon channel; 0 when the data was not binned.
  • n_channels::Float64: Shannon channels the fitted q range holds, (q_max - q_min)·D/π.
  • q_raw, I_raw, σ_raw: the measured curve as given.
  • q, I, σ: the curve the fit sees (binned, then non-positive bins dropped).
  • bin::Vector{Int}: for each raw point, the index into q of its bin; 0 if that bin was dropped.
  • n_nonpositive::Int: bins dropped for I ≤ 0.
source
BAYSOL.Utils.Shannon.auto_lmax — Method

Spherical-harmonic band limit the forward model needs for a particle of diameter D at momentum transfers up to q_max: ceil(q_max·D), the usual q·D_max multipole resolution rule of thumb.

Returns

  • Int: the band limit, at least 1.

Exceptions

  • DomainError: D or q_max is not positive and finite.
source
BAYSOL.Utils.Shannon.bin_bias_ratio — Method

Worst-case bias of the binning against the precision of the binned points, as a fraction of the smallest binned relative error.

A binned point is the mean of the curve over a bin of width Δq = π/(rebin·D), not its value at the bin's mean q; the relative difference is about (Δq²/24)·|I″/I|. For a particle of diameter D, I(q) is the Fourier transform of a function supported on [0, D], so |I″/I| ≤ (D/2)² and the bias is at most π²/(96·rebin²) whatever the size (a typical protein is several times smoother). Dividing by the smallest σ/I of the binned curve says whether the bias can matter; shannon_data makes the bins finer until the ratio is at most BIN_BIAS_MAX.

Returns

  • Float64: the ratio; NaN when the data was not binned.
source
BAYSOL.Utils.Shannon.cloud_diameter — Method

Diameter of a point cloud: the largest distance between two of its points.

The farthest pair of a set is always a pair of vertices of its convex hull, so the hull is built with Quickhull.jl and only its vertices (typically ~100 of thousands of points) are compared. Fewer than four points, or a degenerate (collinear, coplanar or repeated) cloud, has no 3-D hull and is compared pair by pair.

Arguments

  • points::AbstractMatrix{<:Real}: (3, n) coordinates, one column per point; n ≥ 1.

Returns

  • Float64: the diameter, in the units of points (0 for a single point).

Exceptions

  • ArgumentError: points is not 3-by-n, or has no column.
source
BAYSOL.Utils.Shannon.model_on_raw — Method

A model curve given on the fitted (binned) grid, interpolated onto the measured grid by an interpolating cubic spline in q (FITPACK through Dierckx.jl: not-a-knot ends, non-uniform knots, linear extrapolation beyond the end bins; a lower degree when the fitted grid has fewer than four points). Cubics are reproduced exactly. On crambin's forward model the worst error is 0.001 σ for 1 % data at the default rebin (0.06 σ at rebin = 4), where linear interpolation reaches 0.25 σ (1.8 σ); a natural spline (zero curvature at the ends) was tried and is 200× worse there.

Arguments

  • info::ShannonInfo.
  • y::AbstractVector{<:Real}: the model at info.q.

Returns

  • Vector{Float64}: the model at info.q_raw.

Exceptions

  • DimensionMismatch: y is not as long as info.q.
  • ArgumentError: the fitted grid has fewer than two points.

BAYSOL.Utils.Shannon.residual_structure — Method

Whether normalized residuals r = (I - model)/σ are white, as the likelihood assumes.

Returns

A named tuple:

  • lag1: the lag-1 autocorrelation Σ rᵢrᵢ₊₁ / Σ rᵢ²; ≈ 0 ± 1/√n for white residuals.
  • runs_z: Wald–Wolfowitz runs-test z-score of the residual signs; ≈ N(0,1) for white residuals, strongly negative when residuals come in long same-sign runs (NaN if all residuals have one sign).
source
BAYSOL.Utils.Shannon.shannon_data — Method

Bins a measured curve by Shannon channel, drops the bins with non-positive intensity, and picks the band limit.

The curve is cut into bins of width π/(rebin·D) in q, and each bin is replaced by the inverse-variance weighted mean of its points (position and intensity), with the standard error 1/√Σ(1/σᵢ²). Bins narrower than the data's own spacing change nothing. Bins whose mean intensity is not positive (noise at high q) are then dropped, unless drop_nonpositive = false. With rebin = nothing the curve is not binned, only filtered. Dropping is not neutral: it removes the negative half of the noise at high q, so the surviving points are biased upwards.

Arguments

  • q, I, σ: the measured curve, equal lengths, σ > 0, finite.

Keywords

  • D::Real: diameter of the scatterer cloud in Å (see cloud_diameter).
  • rebin::Union{Nothing,Integer} = SHANNON_REBIN: bins per Shannon channel, at least this many (see max_bin_bias), or nothing for no binning.
  • max_bin_bias::Real = BIN_BIAS_MAX: if bin_bias_ratio of the binned curve exceeds this, rebin is raised until it does not (a precise curve needs finer bins), and the curve is fitted as measured once the bins are as fine as its points; Inf keeps rebin as given.
  • lMax::Union{Nothing,Integer} = nothing: band limit; nothing takes auto_lmax(D, q_max) with q_max the largest binned q.
  • drop_nonpositive::Bool = true: drop the bins whose mean intensity is not positive.

Returns

  • ShannonInfo.

Exceptions

  • DomainError: lengths differ, q, I or σ is not finite, σ ≤ 0, rebin < 1, or D ≤ 0.
  • ArgumentError: no point has a positive binned intensity.
