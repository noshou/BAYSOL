MolecularStructure

The structure-loading pipeline (src/MolecularStructure/): the atomic/ionic radius lookup, resolving a structure source (local path, PDB ID, URL), and the Molecule data model. Hydrogen placement is in Hydrogenator.

BAYSOL.MolecularStructure.AMBER_NUCLEIC_NAMES — Constant

Nucleic-acid residue names that are not (or not only) wwPDB component ids but occur in pdb2pqr/Amber output and in older files, with their class and plain parent base: RNA RA RC RG RU and DNA DA DC DG DT, each also with the terminal suffixes 5, 3 and N (RA5, RG3, DAN, ...). component reports them as nucleotides (:rna/:dna, "rna linking"/"dna linking", parent the plain base: A C G U or DA DC DG DT, and the formula and hydrogen count of that base) before consulting the table, because the table also uses several of them (DA5, RG3, ...) for unrelated ligands. The one exception is RU, which the table has as ruthenium: it is left to the table, and a residue named so is taken as uracil only by the backbone-atom test of Hydrogenator.hydrogenation_choice. The CHARMM/old free-base ids ADE CYT GUA THY URA are not here: the wwPDB uses them for the free bases (non-polymers).

source
BAYSOL.MolecularStructure.BACKBONE_ATOMS — Constant

The sugar-phosphate backbone atoms of a nucleotide residue (primes spelled '; the old * is read as '), the evidence for a nucleic acid whose residue names are unknown or legacy: a residue with at least BACKBONE_MIN of them is a nucleotide.

source
BAYSOL.MolecularStructure.BACKBONE_MIN — Constant

How many BACKBONE_ATOMS make an unknown or legacy-named residue a nucleotide.

source
BAYSOL.MolecularStructure.CHAIN_LETTERS — Constant

The chain ids a chain that reuses an id (same residue numbers) is relabelled with, in order: A-Z, a-z, 0-9. Chain ids never reach the scattering model.

BAYSOL.MolecularStructure.DUMMY_MAX_HEAVY_ATOMS — Constant

An ATOM-record residue (not an ion, a water or a small ligand) with at most this many heavy atoms is dummy-like: a C-alpha-only linker residue, a bead.

BAYSOL.MolecularStructure.DUMMY_RESIDUE_NAMES — Constant

Residue names that mark a dummy residue (CORAL/EOM linkers, bead models, unknown placeholders): UNK DUM DUMMY UNL. See dummy_like_residues.

source
BAYSOL.MolecularStructure.DUMMY_ZERO_FRACTION — Constant

A structure in which more than this fraction of the atoms have a B-factor of exactly 0.00 and an occupancy of 0 is flagged as dummy-like (placeholder atoms).

source
BAYSOL.MolecularStructure.DUMMY_ZERO_MAX_FRACTION — Constant

Above this fraction the zero-B, zero-occupancy rule does not fire: a file whose atoms all have occupancy 0 and B 0 (SASDR99) carries no information about which atoms are dummies.

source
BAYSOL.MolecularStructure.LEGACY_NUCLEOTIDE_NAMES — Constant

Legacy residue ids (CHARMM and older files) of the nucleotide bases, with the base they stand for: ADE A, GUA G, CYT C, URI U, THY T. The wwPDB uses these ids for the free bases (non-polymer ligands), so component keeps them :other; a residue under one of these names is a nucleotide only when it carries the sugar-phosphate backbone (legacy_nucleotides): it has a P atom, or at least BACKBONE_MIN of the BACKBONE_ATOMS and its chain has at least two such residues. DAD DCY DGU DTH are not here: the table has them as D-amino acids and a sugar.

source
BAYSOL.MolecularStructure.NUCLEOBASE_ATOMS — Constant

The ring atoms of the nucleobases: a nucleotide residue with fewer than BACKBONE_MIN backbone atoms and none of these is a fragment (a phosphate split off as a residue).

source
BAYSOL.MolecularStructure.PROTEIN_BACKBONE_ATOMS — Constant

The backbone atoms a protein residue must have to be a real residue: N, CA, C.

source
BAYSOL.MolecularStructure.STANDARD_AMINO_ACIDS — Constant

The twenty standard amino acids: a HETATM amino acid with another name is modified (MSE, SEP) and is hydrogenated through its parent (amino_parent).

BAYSOL.MolecularStructure.STANDARD_NUCLEOTIDES — Constant

The wwPDB standard and placeholder nucleotide ids: the four RNA and four DNA bases, uridine in DNA (DU), inosine (I, DI) and the unknown bases (N, DN, T). A nucleotide of any other id is modified (a terminal variant such as 0C or an unnatural nucleotide), whether or not the dictionary declares a parent for it.

BAYSOL.MolecularStructure.ComponentError — Type

Raised when a residue cannot be looked up: it is not in the bundled table, not in the cache and the download failed (typically offline), or its cached file is not a component file. (A name the dictionary answers "no such component" for is not an error: it is taken as an unknown, non-nucleotide residue.)

source
BAYSOL.MolecularStructure.ComponentInfo — Type

The record of a component: id (upper case), class (:dna, :rna or :other), type (the dictionary's _chem_comp.type, lower case), parent (the standard residue a modified one derives from, see below), formula (as in the dictionary, e.g. "C9 H13 N2 O9 P"), n_hydrogens (hydrogens, deuterium included, of the free component's formula), source (:builtin, :cache or :download: where this lookup found it), base (the natural base A C G U T a DNA/RNA component stands for, nothing when none or not known) and base_source (where base comes from: :parent, :self for a standard residue, :letter the dictionary's one-letter code, :ring the ring chemistry, :name the component's name; :none when base is nothing).

parent is what the dictionary declares, base the base the component stands for, declared or inferred, base_source says which. The inference is offline, in dev/extract_components.clj, validated there against the declared parents, and only the bundled table has it: a component read from a cached or downloaded file has the base of its declared parent, else nothing. Nothing in loading, the force-field choice or the classification depends on parent or base.

parent === nothing means "no declared (or resolvable) parent" and is never an error: the dictionary's list is split and deduplicated (DT, DT is DT), a non-standard parent (TTD) is followed up to a standard id, and what cannot be resolved is nothing. Of the 843 DNA/RNA components of the bundled table 565 declare a parent and 278 do not (14 of those are the standard ids, the rest terminal variants and unnatural nucleotides). Nothing in loading, the force-field choice or the classification depends on the parent.

source
BAYSOL.MolecularStructure.Ion — Type

A parsed ion, e.g. "fe3+" -> Ion("fe", 3).

source
BAYSOL.MolecularStructure.LocalPathSource — Type

A structure already on local disk, at path. A .pdb path is used in place (no storage, no copy — it's already local); a .cif/.mmcif path is converted to a canonical .pdb stored in _store_dir, named after the file's own basename stem (e.g. fixture.cif → "fixture"). Conversion always re-runs (it's cheap and local — there's no "skip the work" benefit to be had here, only deduplication of the resulting file); if a file already exists under that name, the freshly-converted result is byte -compared against it: identical content reuses the existing file, but different content under the same name is a collision and raises StructureSourceError rather than silently overwriting or renaming around it — remove the stale file or use a different filename.

source
BAYSOL.MolecularStructure.Molecule — Type

Fields

  • _name::String: structure identifier (e.g. PDB ID or file stem).
  • _elms::Vector{String}: per-atom element symbol, length n.
  • _n::Int: atom count; set at construction, never recomputed.
  • _cart::Matrix{Float64}, (3, n): centred Cartesian coordinates (x, y, z).
  • _sph::Matrix{Float64}, (3, n): spherical coordinates (r, theta, phi), sharing _cart's column index.
  • _radii::Lazy{Vector{Float64}}: per-atom isolated van der Waals radius (AtomicRadii), length n.
  • _vols::Lazy{Vector{Float64}}: per-atom geometrically-computed excluded volume from excluded_volume, length n.
  • _r_max::Lazy{Float64}: largest per-atom radius in _radii.
  • _tree::Lazy{KDTree}: KDTree over _cart, shared across neighbour queries.

BAYSOL.MolecularStructure.PDBIDSource — Type

A structure identified by its 4-character RCSB PDB ID, e.g. "1CRN". Fetched via BioStructures.retrievepdb and stored in _store_dir under the uppercased ID. A repeat request for the same ID trusts an existing file's presence outright and skips fetching — no re-verification, safe only because a real RCSB ID always refers to the same content.

BAYSOL.MolecularStructure.URLSource — Type

A structure available at an arbitrary url, in either legacy .pdb or mmCIF format (sniffed from the downloaded content, not the URL), stored in _store_dir under the caller-supplied id (never derived from the URL — there's no safe, unique way to do that automatically, so it's the caller's responsibility). BAYSOL.MolecularStructure._infer_element — Method

Fallback element guess from an atom name, for legacy-format PDB files whose element column (columns 77-78) is blank – some pre-remediation-era files predate that column. Digits/whitespace are stripped first (e.g. "1HB2" -> "HB"). For an ATOM record (standard protein/nucleic-acid naming), only the first letter is trusted: "CA" is always the alpha carbon (Carbon), never calcium, under that naming convention. For a HETATM record, a name that spells out a full two-letter element symbol (e.g. an ion literally named "FE"/"ZN"/"NA") is trusted in full; anything else falls back to one letter.

BAYSOL.MolecularStructure._legacy_nucleotides — Method

The legacy-named nucleotide residues (LEGACY_NUCLEOTIDE_NAMES) among records, an iterable of (chain, number, residue name, atom name) text tuples (chain and number, with the insertion code, stripped; atom names with * read as ').

BAYSOL.MolecularStructure._resolve_canonical_pdb — Method

Shared "produce candidate .pdb, then compare-or-write-or-throw" step used by LocalPathSource and URLSource (not PDBIDSource, which has its own simpler fetch-if-missing path). Takes model 1 of the already-parsed BioStructures structure struc, writes it (filtered through _canonical_selector: standard and nucleotide heavy atoms, no waters, ions, ligands or hydrogens) to a temp file, then:

  • if nothing is stored under key yet, moves the temp file into place;
  • if something is and it's byte-identical, discards the temp file and returns the existing path unchanged;
  • if something is and it differs, discards the temp file and throws StructureSourceError.

Wraps any BioStructures.writepdb failure (most notably: a multi-character chain ID, which legacy .pdb cannot represent) in a StructureSourceError.

Arguments

  • struc: a parsed BioStructures structure (from read or retrievepdb).
  • key: stored filename stem, e.g. a local file's basename stem or a URLSource's id.

BAYSOL.MolecularStructure._resolve_parent — Function

The standard parent of a component from the dictionary's raw parent text: comma/blank separated lists are split and deduplicated ("DT, DT" is DT); a single standard id (STANDARD_NUCLEOTIDES) is kept; a single non-standard id (TTD) is followed through the table up to a standard id, with a guard against cycles. nothing when there is no declared parent, the list names several different ones, or the chain does not end in a standard id (standard, the nucleotides' by default). Never an error. parent_of(id) gives the raw parent text of another component (nothing if none or unknown).

BAYSOL.MolecularStructure.dummy_like_residues — Method
dummy_like_residues(path) -> NamedTuple

Find what looks like a dummy-atom or fragment model (CORAL/EOM linker residues, UNK dummy residues, bead models, phosphates split off as separate residues), for which BAYSOL's behaviour is undefined. Detection only: nothing is changed. A text scan, chains as sanitized_copy would relabel them. The rules, per residue:

  1. its name is one of DUMMY_RESIDUE_NAMES and it is an ATOM record (a HETATM UNK is an unknown ligand, as in SASDTK5, not a dummy residue);
  2. an ATOM-record residue with at most DUMMY_MAX_HEAVY_ATOMS heavy atoms, unless the residue is a water, an ion or a component that small itself (a formula of at most that many heavy atoms) or its name cannot be a component id (K+);
  3. a protein residue (the dictionary type names a peptide) lacking one of PROTEIN_BACKBONE_ATOMS;
  4. a nucleotide residue with fewer than BACKBONE_MIN of the BACKBONE_ATOMS and none of the NUCLEOBASE_ATOMS;

and for the structure: duplicate atoms (same chain, residue, atom name, alternate location), and more than DUMMY_ZERO_FRACTION of the atoms with a B-factor of exactly 0.00 and an occupancy of 0.

Returns

(; residues, duplicates, zero_fraction, n): residues, a vector of (; chain, num, name, reasons) for the flagged residues (reasons, symbols :name :few_atoms :protein_backbone :nucleotide_fragment); duplicates, the number of duplicate atoms; zero_fraction, the fraction of atoms with B = 0 and occupancy 0; n, the number of findings (flagged residues, plus one for each structure-level rule that fires).

Exceptions

  • ComponentError: a residue name that could not be looked up (offline) and is needed.
  • SystemError: path cannot be read.

BAYSOL.MolecularStructure.sanitized_copy — Method
sanitized_copy(in_path, out_path) -> Union{Nothing,NamedTuple}

Make the .pdb at in_path readable when it needs it, writing the repaired copy to out_path: a TER-separated block that reuses a chain id and its residue numbers (two molecules both labelled A) is given the next unused chain id (CHAIN_LETTERS), and later copies of true duplicate atoms (same chain after relabelling, residue number, atom name and alternate-location id), which BioStructures refuses and which would count twice in the scattering profile, are dropped. Both are logged (@warn, once per structure). Chain ids never reach the scattering model, so the relabelling changes nothing in the profile; the two real chains stay in the model.

Returns

nothing when the file needs neither (nothing is written), else (; relabelled, dropped), the numbers of chains relabelled and duplicate atoms dropped.

Exceptions

  • MoleculeError: more chains need new ids than there are ids.
  • SystemError: a path cannot be read or written.
